Javascript Basic

Module ini adalah pengenalan dasar pemrograman Javascript, bahasa pemrograman paling populer untuk web development. Setelah menyelesaikan module ini kamu akan memahami dasar-dasar logika pemrograman dan bisa menulis script Javascript sederhana.

  • ✅ Bisa membuat perulangan (for, while, do while)

1. Pengenalan Javascript

Javascript adalah bahasa pemrograman yang berjalan di browser. Bersama HTML dan CSS, Javascript adalah salah satu dari 3 teknologi dasar web.

HTML berfungsi untuk struktur konten, CSS untuk styling, sedangkan Javascript membuat website menjadi interaktif: bisa merespon aksi user, mengubah konten secara dinamis, memvalidasi form, membuat animasi, dan banyak lagi.

Hampir semua website modern menggunakan Javascript. Sekarang Javascript juga bisa berjalan di server (Node.js), mobile app, desktop app, bahkan IoT.

📝 Contoh:

// Ini adalah kode Javascript
alert("Hello World!");
console.log("Pesan ini muncul di console browser");

2. Variabel & Tipe Data

Variabel adalah tempat untuk menyimpan data. Di Javascript ada 3 cara mendeklarasikan variabel:

  • var : cara lama (tidak disarankan lagi)
  • let : variabel yang nilainya bisa berubah
  • const : variabel yang nilainya tetap (tidak bisa diubah)

Tipe data dasar di Javascript:

  • string : teks
  • number : angka
  • boolean : true / false
  • undefined : variabel yang belum diisi nilainya
  • null : nilai kosong

📝 Contoh:

// Deklarasi variabel
let nama = "Andi";
const umur = 25;
let sudahMenikah = false;

// Menampilkan nilai variabel
console.log(nama); // "Andi"
console.log(umur); // 25
console.log(sudahMenikah); // false

// Mengubah nilai variabel let
nama = "Budi"; // ✅ Bisa
umur = 30; // ❌ Error, const tidak bisa diubah

3. Operator

Operator adalah simbol yang digunakan untuk melakukan operasi pada data.

Operator Aritmatika:

  • + Penjumlahan
  • - Pengurangan
  • * Perkalian
  • / Pembagian
  • % Sisa bagi
  • ** Pangkat

📝 Contoh:

let a = 10;
let b = 3;

console.log(a + b); // 13
console.log(a - b); // 7
console.log(a * b); // 30
console.log(a / b); // 3.3333
console.log(a % b); // 1

console.log(a > b); // true
console.log(a === b); // false

console.log(a > 5 && b > 1); // true
console.log(a > 15 || b > 1); // true

4. Percabangan If Else

Percabangan digunakan untuk membuat keputusan di dalam kode. Program akan menjalankan baris kode yang berbeda tergantung kondisi yang terpenuhi.

Struktur percabangan:

  1. if : jika kondisi terpenuhi
  2. else if : jika kondisi sebelumnya tidak terpenuhi tapi kondisi ini terpenuhi
  3. else : jika semua kondisi tidak terpenuhi

📝 Contoh:

let nilai = 75;

if (nilai >= 90) {
  console.log("Nilai A");
} else if (nilai >= 80) {
  console.log("Nilai B");
} else if (nilai >= 70) {
  console.log("Nilai C");
} else if (nilai >= 60) {
  console.log("Nilai D");
} else {
  console.log("Nilai E, Tidak Lulus");
}

// Output: "Nilai C"

5. Perulangan

Perulangan digunakan untuk menjalankan baris kode yang sama berulang kali tanpa menulisnya berulang-ulang.

Jenis perulangan yang umum:

  • for : ketika kamu tahu berapa kali ingin mengulang
  • while : ketika kamu tidak tahu berapa kali ingin mengulang
  • do while : mirip while tapi dijalankan minimal 1 kali

📝 Contoh:

// Perulangan for
for (let i = 1; i <= 5; i++) {
  console.log("Angka: " + i);
}

// Output:
// Angka: 1
// Angka: 2
// Angka: 3
// Angka: 4
// Angka: 5

6. Fungsi

Fungsi adalah blok kode yang bisa dipanggil dan digunakan berulang kali. Fungsi bisa menerima input (parameter) dan mengembalikan output (return value).

Fungsi membuat kode menjadi lebih terstruktur, mudah dibaca, dan tidak perlu menulis kode yang sama berulang-ulang.

📝 Contoh:

// Membuat fungsi
function hitungLuasPersegi(panjang, lebar) {
  let luas = panjang * lebar;
  return luas;
}

// Memanggil fungsi
let hasil1 = hitungLuasPersegi(5, 3);
let hasil2 = hitungLuasPersegi(10, 4);

console.log(hasil1); // 15
console.log(hasil2); // 40

7. Array

Array adalah tipe data khusus yang bisa menyimpan banyak nilai dalam satu variabel. Setiap nilai di array memiliki nomor urut (index) yang dimulai dari 0.

Array bisa menyimpan tipe data apapun: string, number, boolean, bahkan array lain atau object.

📝 Contoh:

// Membuat array
let buah = ["Apel", "Mangga", "Jeruk", "Pisang"];

// Mengakses nilai array
console.log(buah[0]); // "Apel"
console.log(buah[2]); // "Jeruk"

// Mengubah nilai array
buah[1] = "Durian";

// Menambahkan nilai baru
buah.push("Anggur");

console.log(buah); 
// ["Apel", "Durian", "Jeruk", "Pisang", "Anggur"]

8. Object

Object adalah tipe data yang digunakan untuk menyimpan koleksi data berpasangan key-value. Object merepresentasikan sebuah entitas yang memiliki properti.

Jika array seperti daftar, maka object seperti deskripsi dari sebuah benda / orang.

📝 Contoh:

// Membuat object
let mahasiswa = {
  nama: "Andi Pratama",
  umur: 21,
  jurusan: "Teknik Informatika",
  semester: 5,
  aktif: true
};

// Mengakses properti object
console.log(mahasiswa.nama); // "Andi Pratama"
console.log(mahasiswa.jurusan); // "Teknik Informatika"

// Mengubah properti
mahasiswa.semester = 6;

// Menambah properti baru
mahasiswa.ipk = 3.75;
