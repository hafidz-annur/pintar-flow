HTML Basic

Module dasar untuk mempelajari HyperText Markup Language (HTML) bahasa standar untuk membuat struktur halaman website. Cocok untuk pemula yang belum pernah membuat website sama sekali. Ini adalah modul pertama yang harus dipelajari untuk menjadi web developer.

🎯 Learning Objectives

  • ✅ Memahami apa itu HTML dan fungsinya dalam pengembangan website
  • ✅ Memahami struktur dasar dokumen HTML
  • ✅ Dapat menggunakan tag-tag HTML yang paling umum digunakan
  • ✅ Dapat membuat struktur halaman website yang valid
  • ✅ Memahami semantic HTML dan pentingnya
  • ✅ Dapat menambahkan gambar, link, daftar, dan tabel

1. Pengenalan HTML

HTML (HyperText Markup Language) adalah bahasa markup standar yang digunakan untuk membuat struktur dan konten halaman website. HTML adalah pondasi dari semua website di internet. Semua website yang kamu kunjungi setiap hari dibangun menggunakan HTML.

HTML bukan bahasa pemrograman, HTML hanya digunakan untuk mendeskripsikan struktur konten: mana yang judul, paragraf, gambar, link, dan lain sebagainya.

Dengan HTML kamu bisa membuat:

  • ✅ Judul dan paragraf
  • ✅ Gambar dan video
  • ✅ Link antar halaman
  • ✅ Daftar dan tabel
  • ✅ Formulir input
  • ✅ Struktur halaman website

📝 Contoh:

<h1>Judul Halaman</h1>
<p>Ini adalah paragraf teks.</p>

2. Struktur Dasar Dokumen HTML

Setiap dokumen HTML memiliki struktur standar yang wajib diikuti agar browser dapat memahami dan merender halaman dengan benar.

Struktur dasar ini selalu sama di setiap website:

  • <!DOCTYPE html>: Deklarasi tipe dokumen
  • <html>: Root element dari seluruh halaman
  • <head>: Berisi meta data, title, dan resource yang dibutuhkan
  • <body>: Berisi semua konten yang akan terlihat oleh user

📝 Contoh:

✅ Struktur HTML lengkap yang valid:

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Website</title>
</head>
<body>
    <!-- Semua konten website disini -->
    <h1>Hello World!</h1>
    <p>Ini halaman website pertama saya.</p>
</body>
</html>

3. Heading dan Paragraf

Heading dan paragraf adalah elemen paling dasar yang digunakan hampir di setiap halaman website.

HTML menyediakan 6 level heading dari <h1> sampai <h6>:

  • <h1>: Judul utama (paling besar) - hanya boleh 1 per halaman
  • <h2>: Sub judul
  • <h3>: Sub sub judul
  • Dan seterusnya sampai <h6>

Paragraf dibuat dengan tag <p>.

📝 Contoh:

✅ Penggunaan heading dan paragraf yang benar:

<h1>Belajar HTML</h1>

<h2>Pengenalan</h2>
<p>HTML adalah bahasa yang digunakan untuk membuat website.</p>

<h3>Manfaat Belajar HTML</h3>
<p>Dengan menguasai HTML kamu bisa membuat website sendiri.</p>

<h4>Topik yang akan dipelajari</h4>
<p>Kita akan mempelajari tag-tag dasar HTML terlebih dahulu.</p>

4. Link dan Gambar

Link adalah fitur yang membuat website menjadi "hypertext" - kamu bisa berpindah dari satu halaman ke halaman lain. Gambar digunakan untuk menambahkan konten visual ke halaman website.

  • Tag untuk link: <a> dengan atribut href
  • Tag untuk gambar: <img> dengan atribut src dan alt

📝 Contoh:

✅ Membuat link:

<!-- Link ke website eksternal -->
<a href="https://google.com">Kunjungi Google</a>

<!-- Link ke halaman lain -->
<a href="about.html">Tentang Kami</a>

<!-- Tab baru -->
<a href="https://google.com" target="_blank">Google di tab baru</a>

✅ Menambahkan gambar:

<img src="logo.png" alt="Logo Perusahaan" width="200" height="100">

<img src="https://example.com/gambar.jpg" alt="Contoh Gambar">

5. Daftar (List)

HTML mendukung 2 jenis daftar:

  1. Ordered List (<ol>) : Daftar berurutan dengan nomor
  2. Unordered List (<ul>) : Daftar tidak berurutan dengan bullet

Setiap item di dalam daftar menggunakan tag

  • .

    • 📝 Contoh:

    ✅ Daftar berurutan:

    <ol>
    <li>Persiapkan bahan</li>
    <li>Campur semua bahan</li>
    <li>Masak selama 15 menit</li>
    <li>Sajikan selagi hangat</li>
</ol>

    ✅ Daftar berurutan

    <ul>
    <li>Apel</li>
    <li>Pisang</li>
    <li>Jeruk</li>
    <li>Mangga</li>
</ul>

    ✅ Daftar tidak berurutan

    6. Tabel

    Tabel digunakan untuk menampilkan data dalam bentuk baris dan kolom.

    Struktur dasar tabel:

    • <table>: Container tabel
    • <tr>: Table Row (baris)
    • <th>: Table Header (judul kolom)
    • <td>: Table Data (isi sel)

    📝 Contoh:

    ✅ Membuat tabel sederhana:

    <table border="1">
    <tr>
        <th>Nama</th>
        <th>Umur</th>
        <th>Kota</th>
    </tr>
    <tr>
        <td>Budi</td>
        <td>25</td>
        <td>Jakarta</td>
    </tr>
</table>

    7. Semantic HTML

    Semantic HTML adalah tag yang memiliki makna dan tujuan jelas, bukan hanya untuk styling. Menggunakan semantic HTML sangat penting untuk aksesibilitas, SEO, dan kemudahan maintenance.

    Tag semantic yang umum:

    • <header>: Bagian kepala halaman
    • <nav>: Menu navigasi
    • <main>: Konten utama
    • <section>: Bagian dari halaman
    • <article>: Konten independen
    • <aside>: Konten samping
    • <footer>: Bagian kaki halaman

    📝 Contoh:

    ✅ Struktur halaman dengan semantic HTML: 

    <header>
    <h1>Nama Website</h1>
    <nav>
        <!-- menu disini -->
    </nav>
</header>

<main>
    <article>
        <h2>Judul Artikel</h2>
        <p>Isi artikel disini...</p>
    </article>
</main>

<footer>
    <p>Copyright &copy; 2026</p>
</footer>
