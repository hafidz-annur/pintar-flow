1. Pengenalan Git & Version Control

Git adalah Version Control System (VCS) terdistribusi yang digunakan untuk mencatat setiap perubahan pada file kode selama proses development. Git memungkinkan banyak developer bekerja bersama pada project yang sama tanpa menimpa pekerjaan satu sama lain.

Version Control System membantu kamu:

  • Menyimpan history setiap perubahan kode
  • Kembali ke versi sebelumnya jika terjadi error
  • Bekerja paralel dengan fitur Branch
  • Kolaborasi dengan tim developer lain
  • Mengetahui siapa yang mengubah apa dan kapan

❗ Penting:

Git != GitHub: Git adalah software VCS, sedangkan GitHub adalah platform hosting untuk repository Git.

📝 Contoh:

# Periksa apakah Git sudah terinstal
git --version

# Konfigurasi awal Git
git config --global user.name "Nama Kamu"
git config --global user.email "email@example.com"

# Cek konfigurasi
git config --list

2. Membuat Repository Git

Repository adalah folder project yang di-track oleh Git. Ada 2 cara membuat repository Git:

  1. git init - Membuat repository baru di folder yang sedang aktif
  2. git clone - Menyalin repository yang sudah ada dari remote server

Setiap repository Git memiliki 3 area utama:

  • Working Directory - Tempat kamu mengedit file
  • Staging Area - Tempat penampungan perubahan yang akan disimpan
  • Repository - Tempat penyimpanan permanen semua history commit

📝 Contoh:

# Buat folder project baru
mkdir project-kita
cd project-kita

# Inisialisasi Git di folder ini
git init

# Cek status repository
git status

3. Menyimpan Perubahan (Commit)

Commit adalah snapshot permanen dari perubahan file kamu. Setiap commit memiliki ID unik (hash), pesan deskripsi, informasi author, dan waktu pembuatan.

Alur dasar menyimpan perubahan:

  1. Edit file di Working Directory
  2. Tambahkan perubahan ke Staging Area dengan git add
  3. Simpan secara permanen ke Repository dengan git commit

Setiap commit harus memiliki pesan yang jelas dan deskriptif agar mudah dibaca oleh tim lain.

📝 Contoh:

# Tambahkan 1 file ke staging
git add index.html

# Tambahkan semua file yang berubah
git add .

# Simpan perubahan dengan pesan commit
git commit -m "Menambahkan struktur dasar halaman homepage"

# Lihat daftar semua commit
git log

# Lihat log dalam format ringkas
git log --oneline

4. Melihat Perubahan & Membatalkan

Git menyediakan berbagai perintah untuk melihat apa yang berubah, membandingkan versi, dan membatalkan perubahan jika kamu tidak sengaja merusak kode.

Beberapa perintah penting:

  • git diff - Melihat perubahan yang belum di-staging
  • git restore - Membatalkan perubahan di working directory
  • git reset - Menghapus file dari staging area
  • git checkout - Kembali ke commit sebelumnya

📝 Contoh:

# Melihat perubahan yang belum di add
git diff

# Melihat perubahan yang sudah di add tapi belum di commit
git diff --staged

# Membatalkan perubahan file index.html (kembali ke commit terakhir)
git restore index.html

# Menghapus file dari staging area
git reset HEAD index.html

5. Branch & Merge

Branch adalah fitur paling powerful di Git. Branch memungkinkan kamu membuat cabang development terpisah dari kode utama, sehingga kamu bisa mengembangkan fitur baru tanpa merusak kode yang sudah stabil.

Workflow standar:

  1. Buat branch baru untuk setiap fitur
  2. Lakukan development di branch tersebut
  3. Jika selesai dan teruji, gabungkan (merge) kembali ke branch utama main atau master

📝 Contoh:

# Lihat daftar branch yang ada
git branch

# Buat branch baru
git branch fitur-login

# Pindah ke branch yang lain
git checkout fitur-login

# Buat dan pindah sekaligus
git checkout -b fitur-registrasi

# Gabungkan branch ke main
git checkout main
git merge fitur-login

# Hapus branch yang sudah selesai
git branch -d fitur-login

6. Remote Repository & GitHub

Remote Repository adalah salinan repository Git yang berada di server internet (seperti GitHub, GitLab, Bitbucket). Remote memungkinkan kamu mensinkronkan pekerjaan lokal dengan tim developer lain.

Perintah dasar untuk bekerja dengan remote:

  • git remote add - Menghubungkan repository lokal ke remote
  • git push - Mengirim commit lokal ke remote
  • git pull - Mengambil commit terbaru dari remote ke lokal
  • git clone - Menyalin repository dari remote ke komputer lokal

📝 Contoh:

# Hubungkan lokal ke GitHub
git remote add origin https://github.com/username/project-kita.git

# Kirim commit lokal ke GitHub
git push origin main

# Ambil update terbaru dari GitHub
git pull origin main

# Clone repository yang sudah ada
git clone https://github.com/username/project-kita.git
