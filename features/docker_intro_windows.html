Pengertian Docker dan Cara Setup di Windows

Module ini menjelaskan secara mendalam apa itu Docker, konsep dasar containerization, dan langkah demi langkah cara install dan setup Docker Desktop di sistem operasi Windows dengan benar. Cocok untuk pemula yang ingin mulai menggunakan Docker.

🎯 Learning Objectives

  • ✅ Memahami apa itu Docker dan perbedaannya dengan Virtual Machine
  • ✅ Memahami konsep Image, Container, Registry, dan Dockerfile
  • ✅ Bisa menginstall Docker Desktop di Windows dengan benar
  • ✅ Memahami konfigurasi WSL 2 backend untuk Docker
  • ✅ Bisa menjalankan container pertama
  • ✅ Memahami perintah dasar Docker CLI
  • ✅ Bisa troubleshooting masalah umum Docker di Windows

1. Apa Itu Docker?

Docker adalah platform open source untuk mengembangkan, mengirim, dan menjalankan aplikasi di dalam container. Container memungkinkan kamu membungkus aplikasi dengan semua dependensinya menjadi satu paket standar.

Perbedaan Container vs Virtual Machine:

  • VM menjalankan seluruh sistem operasi penuh
  • Container hanya menjalankan aplikasi dan berbagi kernel host OS
  • Container jauh lebih ringan, cepat start, dan hemat resource
  • Container menjamin lingkungan yang sama dari development sampai production

💡 Contoh:

✅ Tanpa Docker:
"Di laptop saya jalan, kenapa di server error?"

✅ Dengan Docker:
"Di semua tempat jalan sama persis"

2. Konsep Dasar Docker

4 konsep inti yang harus kamu pahami:

  • Image: Template read-only yang berisi instruksi untuk membuat container. Seperti blueprint aplikasi.
  • Container: Instance berjalan dari sebuah image. Kamu bisa membuat banyak container dari image yang sama.
  • Dockerfile: File teks yang berisi perintah untuk membangun image secara otomatis.
  • Registry: Tempat penyimpanan dan berbagi image. Docker Hub adalah registry publik paling populer.

3. Persyaratan Instalasi Docker di Windows

Docker Desktop untuk Windows memiliki 2 backend yang bisa dipilih:

✅ WSL 2 Backend (REKOMENDASI)

  • Windows 10 21H2 atau lebih baru / Windows 11
  • Minimal RAM 4GB (disarankan 8GB+)
  • Fitur Virtualization diaktifkan di BIOS/UEFI

⚠️ Hyper-V Backend

  • Untuk Windows versi lama
  • Hanya untuk Windows Pro, Enterprise, atau Education
  • Kurang performa dibanding WSL 2

⚠️ Penting: Pastikan Virtualization sudah diaktifkan di BIOS kamu sebelum install Docker.

4. Langkah Instalasi Docker Desktop

Langkah demi langkah instalasi:

  1. Download Docker Desktop dari situs resmi docker.com
  2. Jalankan installer
  3. Pilih opsi "Use WSL 2 instead of Hyper-V"
  4. Tunggu sampai instalasi selesai
  5. Restart komputer kamu
  6. Jalankan Docker Desktop
  7. Terima persyaratan layanan
  8. Tunggu sampai Docker selesai melakukan inisialisasi
Ketika kamu melihat pesan "Docker Desktop is running" berarti instalasi sudah berhasil.

5. Verifikasi Instalasi

Setelah instalasi selesai, buka Command Prompt / text / Terminal dan jalankan perintah ini untuk memverifikasi:

📝 Contoh:

# Cek versi Docker
docker --version

# Cek Docker berjalan normal
docker run hello-world
Jika kamu melihat pesan "Hello from Docker!" berarti seluruh instalasi sudah berhasil dan Docker siap digunakan.

6. Perintah Dasar Docker

Perintah yang paling sering digunakan:

Perintah Fungsi
docker pull [image] Mengunduh image dari registry
docker run [image] Membuat dan menjalankan container baru
docker ps Melihat daftar container yang berjalan
docker ps -a Melihat semua container
docker stop [id] Menghentikan container
docker rm [id] Menghapus container
docker images Melihat daftar image yang ada di lokal
docker rmi [image] Menghapus image

📝 Contoh:

# Contoh menjalankan database PostgreSQL
docker run -d -p 5432:5432 -e POSTGRES_PASSWORD=rahasia postgres:15

7. Troubleshooting Masalah Umum

Masalah yang paling sering terjadi di Windows dan solusinya:

❌ WSL 2 installation is incomplete

✅ Download dan install update kernel WSL 2 dari website Microsoft

❌ Docker stuck starting

✅ Restart Docker Desktop, restart WSL dengan wsl --shutdown

❌ Performance lambat

✅ Pastikan menggunakan WSL 2 backend, bukan Hyper-V

❌ Tidak bisa akses container dari localhost

✅ Pastikan kamu mempublish port dengan flag -p ketika docker run

8. Tips Menggunakan Docker di Windows

  • Gunakan Terminal Windows terbaru untuk pengalaman terbaik
  • Jangan menyimpan file project di Windows filesystem, simpan di dalam WSL distro untuk performa maksimal
  • Batasi resource memory dan CPU Docker di Settings > Resources
  • Aktifkan "Start Docker Desktop when you log in" agar Docker otomatis berjalan
  • Selalu gunakan versi tag image yang spesifik, jangan gunakan latest
