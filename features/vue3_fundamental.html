1. Pengenalan Vue 3

Vue 3 adalah versi terbaru dari Vue.js, Progressive JavaScript Framework yang fokus pada View Layer. Vue 3 menawarkan performa yang lebih cepat, bundle size yang lebih kecil, API yang lebih baik, dan dukungan penuh untuk TypeScript.

Keunggulan utama Vue 3:

  • ✅ Lebih cepat dan ringan
  • ✅ Composition API sebagai alternatif Options API
  • ✅ Reactivity System yang ditingkatkan
  • ✅ Built-in Teleport, Suspense, dan Multiple v-model
  • ✅ Dukungan penuh TypeScript
  • ✅ Tree-shaking yang lebih baik

Vue 3 adalah framework yang mudah dipelajari tapi cukup powerful untuk membangun aplikasi skala besar.

📝 Contoh:

# Buat project baru
npm create vite@latest my-vue-app -- --template vue

cd my-vue-app
npm install
npm run dev

Struktur project Vue 3:

my-vue-app/
├── src/
│   ├── components/
│   ├── App.vue
│   └── main.js
├── index.html
├── package.json
└── vite.config.js

2. Dasar Composition API & Script Setup

Composition API adalah fitur andalan Vue 3 yang memungkinkan kamu mengorganisir logic berdasarkan fitur, bukan berdasarkan jenis opsi seperti pada Options API.

script setup adalah syntax sugar yang membuat penggunaan Composition API menjadi jauh lebih sederhana dan ringkas. Semua yang kamu deklarasikan di dalam script setup akan otomatis tersedia di template.

Di dalam script setup kamu bisa menggunakan:

  • ref() untuk membuat reactive value primitif
  • reactive() untuk membuat reactive object
  • computed() untuk membuat computed property
  • watch() untuk memantau perubahan value
  • onMounted() dan lifecycle hooks lainnya

📝 Contoh:

<script setup>
import { ref, computed, onMounted } from 'vue'

// Reactive variable
const counter = ref(0)

// Computed property
const doubled = computed(() => counter.value * 2)

// Method
function increment() {
  counter.value++
}

// Lifecycle Hook
onMounted(() => {
  console.log('Component sudah terload!')
})
</script>

<template>
  <div>
    <p>Counter: {{ counter }}</p>
    <p>Double: {{ doubled }}</p>
    <button @click="increment">Tambah</button>
  </div>
</template>

3. Directive Dasar Vue

Directive adalah atribut khusus v-* yang memberikan kemampuan khusus pada template. Directive yang paling sering digunakan:

Directive Fungsi
v-bind Mengikat value ke atribut HTML
v-model Two way binding untuk form input
v-on / @ Menangani event
v-if / v-else Kondisional render
v-for Looping array / object
v-show Toggle visibility dengan CSS

Setiap directive memiliki aturan penggunaan dan kasus tersendiri.

📝 Contoh:

<script setup>
import { ref } from 'vue'

const nama = ref('')
const users = ref(['Ahmad', 'Budi', 'Citra'])
const isActive = ref(true)
</script>

<template>
  <!-- v-model two way binding -->
  <input v-model="nama" placeholder="Masukkan nama">

  <!-- v-bind atribut -->
  <button :class="isActive ? 'bg-blue-500' : 'bg-gray-500'">
    Submit
  </button>

  <!-- v-for looping -->
  <ul>
    <li v-for="user in users" :key="user">
      {{ user }}
    </li>
  </ul>

  <!-- v-if kondisional -->
  <div v-if="nama">
    Halo {{ nama }}!
  </div>
  <div v-else>
    Silahkan masukkan nama kamu
  </div>
</template>

4. Membuat Component

Komponen adalah blok bangunan dasar aplikasi Vue. Setiap aplikasi Vue dibangun dari pohon komponen yang saling terhubung.

Setiap komponen Vue 3:

  • Berada di file dengan ekstensi .vue
  • Memiliki 3 bagian: script, template, dan style
  • Dapat diimport dan digunakan di komponen lain
  • Bersifat reusable dan reusable

💡 Best Practice:

Selalu buat komponen yang kecil, fokus pada satu tanggung jawab saja, dan mudah digunakan kembali.

📝 Contoh:

<!-- src/components/Card.vue -->

<script setup>
defineProps({
  title: {
    type: String,
    required: true
  }
})
</script>

<template>
  <div class="bg-white rounded-lg shadow p-6">
    <h3 class="text-xl font-bold mb-4">{{ title }}</h3>
    <slot />
  </div>
</template>

Menggunakan komponen di App.vue:

<script setup>
import Card from './components/Card.vue'
</script>

<template>
  <Card title="Judul Card">
    <p>Ini adalah konten dari slot</p>
  </Card>
</template>

5. Props & Emits

Props dan Emits adalah cara standar untuk komunikasi antar komponen di Vue 3:

  • ✅ Props: Mengirim data dari Parent Component ke Child Component
  • ✅ Emits: Mengirim event dari Child Component ke Parent Component

Alur data di Vue adalah One Way Data Flow:

Data mengalir turun ke bawah melalui props, event mengalir naik ke atas melalui emits.

Contoh alur data:

App.vue → UserList.vue → UserCard.vue

📝 Contoh:

Child Component (ButtonCounter.vue):

<script setup>
const emit = defineEmits(['count'])

let count = $ref(0)

function increment() {
  count++
  emit('count', count)
}
</script>

<template>
  <button @click="increment">
    Diklik {{ count }} kali
  </button>
</template>

Parent Component:

<script setup>
import ButtonCounter from './ButtonCounter.vue'

function onCount(value) {
  console.log('Counter value:', value)
}
</script>

<template>
  <ButtonCounter @count="onCount" />
</template>

6. Contoh Aplikasi Todo List

Kita akan mengimplementasikan semua yang sudah dipelajari untuk membuat aplikasi Todo List sederhana yang memiliki fitur:

  • Menampilkan daftar todo
  • Menambah todo baru
  • Menandai todo selesai
  • Menghapus todo
  • Menghitung jumlah todo yang belum selesai

Aplikasi ini menggunakan semua konsep dasar Vue 3 yang sudah kita pelajari.

📝 Contoh:

<script setup>
import { ref, computed } from 'vue'

const newTodo = ref('')
const todos = ref([
  { id: 1, text: 'Belajar Vue 3', done: false },
  { id: 2, text: 'Mengerjakan latihan', done: false }
])

function addTodo() {
  if (newTodo.value.trim()) {
    todos.value.push({
      id: Date.now(),
      text: newTodo.value,
      done: false
    })
    newTodo.value = ''
  }
}

function toggleTodo(id) {
  const todo = todos.value.find(t => t.id === id)
  if (todo) todo.done = !todo.done
}

function deleteTodo(id) {
  todos.value = todos.value.filter(t => t.id !== id)
}

const remaining = computed(() => {
  return todos.value.filter(t => !t.done).length
})
</script>

<template>
  <div class="max-w-md mx-auto">
    <h1 class="text-2xl font-bold mb-4">Todo List</h1>

    <div class="flex gap-2 mb-4">
      <input v-model="newTodo" @keyup.enter="addTodo" class="flex-1 border rounded px-3 py-2">
      <button @click="addTodo" class="bg-blue-500 text-white px-4 py-2 rounded">Add</button>
    </div>

    <p class="mb-4">Sisa: {{ remaining }} todo</p>

    <ul class="space-y-2">
      <li v-for="todo in todos" :key="todo.id" class="flex items-center gap-2 p-3 bg-gray-100 rounded">
        <input type="checkbox" :checked="todo.done" @change="toggleTodo(todo.id)">
        <span :class="{ 'line-through text-gray-400': todo.done }">{{ todo.text }}</span>
        <button @click="deleteTodo(todo.id)" class="ml-auto text-red-500">×</button>
      </li>
    </ul>
  </div>
</template>
