SQL Basic

Module dasar untuk mempelajari Structured Query Language (SQL) bahasa standar untuk mengelola dan memanipulasi data dalam database relasional. Cocok untuk pemula yang belum pernah menyentuh database sama sekali.

🎯 Learning Objectives

  • ✅ Memahami apa itu SQL dan fungsinya
  • ✅ Dapat menulis query dasar untuk membaca data
  • ✅ Memahami operasi CRUD dasar
  • ✅ Dapat memfilter dan mengurutkan data
  • ✅ Memahami konsep table dan relasi dasar

1. Pengenalan SQL

SQL (Structured Query Language) adalah bahasa standar internasional yang digunakan untuk berkomunikasi dengan database relasional. Hampir semua sistem database modern seperti MySQL, PostgreSQL, SQL Server, SQLite menggunakan SQL sebagai bahasa utamanya.

Dengan SQL kamu bisa:

  • ✅ Membaca data dari database
  • ✅ Menyimpan data baru
  • ✅ Mengubah data yang sudah ada
  • ✅ Menghapus data
  • ✅ Membuat struktur tabel dan database

SQL bukan bahasa pemrograman biasa, SQL adalah bahasa deklaratif: kamu menulis APA yang kamu inginkan, bukan BAGAIMANA cara mendapatkannya.

📝 Contoh:

SELECT * FROM users;

Artinya: "Ambil SEMUA kolom dari tabel bernama users"

2. SELECT Statement

SELECT adalah perintah yang paling sering digunakan di SQL. Fungsinya untuk membaca dan mengambil data dari tabel. Ini adalah operasi Read dalam konsep CRUD.

Kamu bisa memilih kolom mana saja yang ingin diambil, tidak harus semua kolom. Mengambil hanya kolom yang dibutuhkan akan membuat query berjalan lebih cepat dan efisien.

📝 Contoh:

SELECT nama, email, no_hp FROM users;

✅ Mengambil kolom tertentu saja

SELECT 
  nama AS nama_lengkap,
  email AS alamat_email
FROM users;

✅ Memberi nama alias pada kolom

SELECT * FROM users LIMIT 10;

✅ Membatasi jumlah hasil

3. WHERE Clause

WHERE digunakan untuk memfilter data yang akan diambil. Dengan WHERE kamu bisa menentukan kondisi mana saja baris data yang ingin ditampilkan.

Ini adalah fitur paling penting di SQL, karena hampir tidak pernah kamu butuhkan SEMUA data dalam tabel sekaligus.

Operator perbandingan yang bisa digunakan: =, !=, >, <, >=, <=

📝 Contoh:

SELECT * FROM users WHERE status = 'aktif';

✅ Mengambil hanya user yang aktif

SELECT nama, umur FROM users WHERE umur > 17;

✅ Mengambil user yang berumur diatas 17 tahun

SELECT * FROM users 
WHERE status = 'aktif' 
AND umur >= 18
AND kota = 'Jakarta';

✅ Menggabungkan beberapa kondisi dengan AND

4. ORDER BY

ORDER BY digunakan untuk mengurutkan hasil query berdasarkan kolom tertentu. Kamu bisa mengurutkan secara menaik (ASC) atau menurun (DESC).

Secara default jika tidak ditentukan, ORDER BY akan menggunakan urutan ASC.

📝 Contoh:

SELECT nama, email FROM users ORDER BY nama ASC;

✅ Urutkan user berdasarkan nama dari A ke Z

SELECT * FROM users ORDER BY created_at DESC;

✅ Urutkan berdasarkan tanggal pendaftaran terbaru

SELECT * FROM users 
ORDER BY kota ASC, umur DESC;

✅ Urutkan dengan lebih dari satu kolom

5. INSERT Data

INSERT adalah perintah untuk menambahkan baris data baru ke dalam tabel. Ini adalah operasi Create dalam konsep CRUD.

Kamu harus menyebutkan kolom mana yang akan diisi, diikuti dengan nilai-nilai yang sesuai.

📝 Contoh:

INSERT INTO users (nama, email, umur, status)
VALUES ('Budi Santoso', 'budi@email.com', 23, 'aktif');

✅ Menambahkan 1 user baru

INSERT INTO users (nama, email, status) VALUES
  ('Ani Putri', 'ani@email.com', 'aktif'),
  ('Dedi Rahman', 'dedi@email.com', 'pending'),
  ('Siti Aminah', 'siti@email.com', 'aktif');

✅ Menambahkan banyak data sekaligus

6. UPDATE Data

UPDATE digunakan untuk mengubah data yang sudah ada di dalam tabel. Ini adalah operasi Update dalam konsep CRUD.

⚠️ PERINGATAN PALING PENTING:

Selalu gunakan WHERE saat UPDATE! Jika lupa menambahkan WHERE, SEMUA baris di tabel akan berubah!

📝 Contoh:

UPDATE users 
SET email = 'budi_baru@email.com'
WHERE id = 5;

✅ Mengubah email user tertentu

UPDATE users
SET 
  status = 'nonaktif',
  updated_at = NOW()
WHERE terakhir_login < '2025-01-01';

✅ Mengubah lebih dari satu kolom sekaligus

7. DELETE Data

DELETE adalah perintah untuk menghapus baris data dari tabel. Ini adalah operasi Delete dalam konsep CRUD.

⚠️ PERINGATAN TERHEBAT:

DELETE bersifat permanen! Tidak ada undo, tidak ada recycle bin di SQL standard.

Selalu gunakan WHERE! Jangan pernah DELETE tanpa WHERE.

📝 Contoh:

DELETE FROM users WHERE id = 12;

✅ Menghapus user dengan id tertentu

DELETE FROM users 
WHERE status = 'nonaktif'
AND terakhir_login < '2024-01-01';

✅ Menghapus user yang sudah tidak aktif
