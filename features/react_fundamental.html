React Fundamental

Module ini akan memperkenalkan kamu tentang dasar-dasar React.js, JavaScript library yang paling populer untuk membangun user interface. Kamu akan mempelajari konsep inti React, JSX syntax, component, state, props, hooks, dan fitur-fitur utama React yang digunakan dalam development aplikasi modern.

1. Pengenalan React

React adalah JavaScript library yang dikembangkan oleh Meta (Facebook) untuk membangun user interface, khususnya untuk single-page application. React berfokus pada View Layer dan memungkinkan developer membuat UI yang interaktif dengan cara yang deklaratif.

Keunggulan utama React:

  • ✅ Component-based architecture - UI dibangun dari komponen yang reusable
  • ✅ Virtual DOM - Performa rendering yang optimal
  • ✅ Unidirectional data flow - Alur data yang mudah diprediksi
  • ✅ JSX syntax - Menulis HTML-like syntax di JavaScript
  • ✅ Ekosistem yang besar - Banyak library dan tools pendukung
  • ✅ React Native - Bisa digunakan untuk mobile development

React adalah library yang powerful dan fleksibel, cocok untuk aplikasi kecil hingga skala besar.

📝 Contoh:

Membuat project React dengan Vite:

# Buat project baru
npm create vite@latest my-react-app -- --template react

cd my-react-app
npm install
npm run dev

Struktur project React:

├── src/
│   ├── components/
│   ├── App.jsx
│   ├── App.css
│   ├── main.jsx
│   └── index.css
├── index.html
├── package.json
└── vite.config.js

2. JSX Syntax

JSX (JavaScript XML) adalah syntax extension untuk JavaScript yang memungkinkan kamu menulis HTML-like syntax di dalam file JavaScript. JSX bukan string HTML biasa, melainkan syntax yang akan dikompilasi menjadi JavaScript.

Aturan penting JSX:

  • Harus return satu parent element (atau gunakan Fragment <>...</>)
  • Gunakan className bukan class untuk CSS class
  • Gunakan htmlFor bukan for untuk label
  • Inline styles menggunakan camelCase (contoh: backgroundColor)
  • JavaScript expression ditulis di dalam curly braces {}

JSX membuat kode React lebih mudah dibaca dan ditulis, terutama untuk UI yang kompleks.

📝 Contoh:

// Contoh JSX dasar
function App() {
  const name = 'React Developer'
  const isLoggedIn = true
  const items = ['Item 1', 'Item 2', 'Item 3']

  return (
    <div className="container">
      <h1>Halo, {name}!</h1>

      {isLoggedIn ? (
        <p>Selamat datang di aplikasi React</p>
      ) : (
        <p>Silahkan login terlebih dahulu</p>
      )}

      <ul>
        {items.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>

      <button style={{ backgroundColor: 'blue', color: 'white' }}>
        Klik Saya
      </button>
    </div>
  )
}

3. Component & Props

Component adalah blok bangunan dasar di React. Setiap component adalah fungsi JavaScript yang mengembalikan JSX. Component memungkinkan kita memecah UI menjadi bagian-bagian kecil yang reusable.

Props (properties) adalah cara untuk mengirim data dari parent component ke child component. Props bersifat read-only (immutable) - child component tidak boleh mengubah props yang diterima.

Jenis component di React:

  • Functional Component: Function yang return JSX (recommended)
  • Class Component: Class ES6 yang extend React.Component (legacy)

💡 Best Practice:

Selalu buat component yang kecil, fokus pada satu tanggung jawab, dan mudah digunakan kembali.

📝 Contoh:

<!-- Parent Component (App.jsx) -->

import UserProfile from './UserProfile'

function App() {
  const user = {
    name: 'John Doe',
    email: 'john@example.com',
    role: 'Developer'
  }

  return (
    <div>
      <UserProfile
        name={user.name}
        email={user.email}
        role={user.role}
      />
      <UserProfile
        name="Jane Smith"
        email="jane@example.com"
        role="Designer"
      />
    </div>
  )
}

Child Component (UserProfile.jsx):

function UserProfile({ name, email, role }) {
  return (
    <div className="user-card">
      <h2>{name}</h2>
      <p>{role}</p>
      <p>{email}</p>
    </div>
  )
}

export default UserProfile

4. State & useState Hook

State adalah data yang dapat berubah (mutable) di dalam component. Ketika state berubah, React akan re-render component tersebut. State membuat component menjadi interaktif dan dinamis.

useState adalah Hook yang memungkinkan functional component memiliki state. Hook adalah fungsi khusus yang hanya bisa dipanggil di level atas component.

Cara kerja useState:

const [stateValue, setStateFunction] = useState(initialValue)
  • stateValue: nilai state saat ini
  • setStateFunction: function untuk mengupdate state
  • initialValue: nilai awal state

⚠️ Penting:

Selalu gunakan setState function untuk mengupdate state, jangan langsung assign nilai!

📝 Contoh:

import { useState } from 'react'

function Counter() {
  // State untuk counter
  const [count, setCount] = useState(0)

  // State untuk input text
  const [text, setText] = useState('')

  // State untuk array
  const [items, setItems] = useState([])

  function increment() {
    setCount(count + 1)
    // Atau: setCount(prevCount => prevCount + 1)
  }

  function addItem() {
    if (text.trim()) {
      setItems([...items, text])
      setText('')
    }
  }

  return (
    <div>
      <h2>Counter: {count}</h2>
      <button onClick={increment}>Tambah</button>

      <hr />

      <input
        value={text}
        onChange={(e) => setText(e.target.value)}
        placeholder="Masukkan item"
      />
      <button onClick={addItem}>Tambah Item</button>

      <ul>
        {items.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
    </div>
  )
}

5. Event Handling

Event handling di React mirip dengan DOM events, tetapi with beberapa perbedaan:

  • Event di React menggunakan camelCase (onClick, onChange, onSubmit)
  • Handler menerima SyntheticEvent (wrapper React untuk event browser)
  • Untuk mencegah default behavior, gunakan e.preventDefault()
  • Event handler biasanya berupa arrow function atau method reference

Event yang sering digunakan:

  • onClick - Klik mouse
  • onChange - Perubahan value (input, select, textarea)
  • onSubmit - Submit form
  • onMouseEnter / onMouseLeave - Hover
  • onKeyDown / onKeyUp - Keyboard events

📝 Contoh:

import { useState } from 'react'

function EventDemo() {
  const [formData, setFormData] = useState({
    username: '',
    email: '',
    message: ''
  })

  // Handle input change
  function handleChange(e) {
    const { name, value } = e.target
    setFormData(prev => ({
      ...prev,
      [name]: value
    }))
  }

  // Handle form submit
  function handleSubmit(e) {
    e.preventDefault()
    console.log('Form submitted:', formData)
    alert('Form berhasil dikirim!')
  }

  // Handle button click
  function handleClick(message) {
    console.log(message)
  }

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>Username:</label>
        <input
          type="text"
          name="username"
          value={formData.username}
          onChange={handleChange}
        />
      </div>

      <div>
        <label>Email:</label>
        <input
          type="email"
          name="email"
          value={formData.email}
          onChange={handleChange}
        />
      </div>

      <div>
        <label>Message:</label>
        <textarea
          name="message"
          value={formData.message}
          onChange={handleChange}
        />
      </div>

      <button type="submit">Kirim</button>
      <button type="button" onClick={() => handleClick('Button clicked!')}>
        Test Click
      </button>
    </form>
  )
}

6. useEffect Hook

useEffect adalah Hook yang memungkinkan kamu menjalankan side effects di functional component. Side effects adalah operasi yang mempengaruhi sesuatu di luar component, seperti:

  • Fetching data dari API
  • Manipulasi DOM langsung
  • Setting up subscriptions atau timers
  • Logging

useEffect dijalankan setelah render selesai, dan bisa dijalankan ulang ketika dependencies berubah.

Syntax:

useEffect(() => {
  // Code yang dijalankan setelah render
  return () => {
    // Cleanup function (optional)
  }
}, [dependencies]) // Array dependencies
  • Jika dependencies kosong [], effect hanya dijalankan sekali (seperti componentDidMount)
  • Jika dependencies berisi variable, effect dijalankan setiap variable berubah
  • Jika tidak ada dependencies, effect dijalankan setiap render

📝 Contoh:

import { useState, useEffect } from 'react'

function TimerComponent() {
  const [count, setCount] = useState(0)
  const [data, setData] = useState(null)

  // Effect tanpa dependencies - dijalankan setiap render
  useEffect(() => {
    console.log('Component rendered')
  })

  // Effect dengan empty dependencies - dijalankan sekali saja
  useEffect(() => {
    console.log('Component mounted')

    // Cleanup function
    return () => {
      console.log('Component will unmount')
    }
  }, [])

  // Effect dengan dependencies - dijalankan saat count berubah
  useEffect(() => {
    console.log(`Count berubah menjadi: ${count}`)
    document.title = `Count: ${count}`
  }, [count])

  // Fetch data dari API
  useEffect(() => {
    async function fetchData() {
      try {
        const response = await fetch('https://api.example.com/data')
        const result = await response.json()
        setData(result)
      } catch (error) {
        console.error('Error fetching data:', error)
      }
    }

    fetchData()
  }, [])

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Tambah
      </button>

      {data && (
        <pre>{JSON.stringify(data, null, 2)}</pre>
      )}
    </div>
  )
}

7. Conditional Rendering & List Rendering

Conditional Rendering adalah teknik menampilkan component atau element berdasarkan kondisi tertentu. Di React, ada beberapa cara untuk conditional rendering:

  • if/else statement
  • Ternary operator condition ? true : false
  • Logical AND condition && element
  • Early return pattern

List Rendering adalah teknik menampilkan daftar element dari array. Di React, gunakan map() function untuk mengubah array menjadi array of JSX elements.

⚠️ Penting:

Selalu berikan key prop yang unique untuk setiap element dalam list. Key membantu React mengidentifikasi item mana yang berubah, ditambah, atau dihapus.

📝 Contoh:

import { useState } from 'react'

function UserList() {
  const [users, setUsers] = useState([
    { id: 1, name: 'Alice', role: 'Admin', active: true },
    { id: 2, name: 'Bob', role: 'User', active: false },
    { id: 3, name: 'Charlie', role: 'User', active: true }
  ])
  const [showInactive, setShowInactive] = useState(true)

  // Filter users berdasarkan kondisi
  const filteredUsers = users.filter(user => {
    return showInactive || user.active
  })

  // Conditional rendering dengan ternary
  const statusBadge = (isActive) => {
    return isActive ? (
      <span className="badge-active">Active</span>
    ) : (
      <span className="badge-inactive">Inactive</span>
    )
  }

  return (
    <div>
      <h2>User List</h2>

      {/* Conditional rendering with logical AND */}
      {users.length === 0 && (
        <p>Tidak ada user</p>
      )}

      {/* Toggle button */}
      <button onClick={() => setShowInactive(!showInactive)}>
        {showInactive ? 'Hide' : 'Show'} Inactive Users
      </button>

      {/* List rendering */}
      <ul>
        {filteredUsers.map((user) => (
          <li key={user.id}>
            <strong>{user.name}</strong>
            <span> - {user.role}</span>
            {statusBadge(user.active)}
          </li>
        ))}
      </ul>

      {/* Conditional rendering with ternary */}
      {filteredUsers.length > 0 ? (
        <p>Total: {filteredUsers.length} users</p>
      ) : (
        <p>Semua user inactive</p>
      )}
    </div>
  )
}

8. Contoh Aplikasi: Task Manager

Kita akan mengimplementasikan semua yang sudah dipelajari untuk membuat aplikasi Task Manager sederhana yang memiliki fitur:

  • Menampilkan daftar task
  • Menambah task baru
  • Menandai task selesai/belum selesai
  • Menghapus task
  • Filter task (All, Active, Completed)
  • Menghitung jumlah task

Aplikasi ini menggunakan semua konsep dasar React yang sudah kita pelajari: state, props, event handling, conditional rendering, dan list rendering.

📝 Contoh:

import { useState } from 'react'

function TaskManager() {
  const [tasks, setTasks] = useState([
    { id: 1, text: 'Belajar React', completed: false },
    { id: 2, text: 'Membuat project', completed: true },
    { id: 3, text: 'Deploy aplikasi', completed: false }
  ])
  const [newTask, setNewTask] = useState('')
  const [filter, setFilter] = useState('all') // 'all', 'active', 'completed'

  // Tambah task baru
  function addTask(e) {
    e.preventDefault()
    if (newTask.trim()) {
      setTasks([
        ...tasks,
        {
          id: Date.now(),
          text: newTask,
          completed: false
        }
      ])
      setNewTask('')
    }
  }

  // Toggle task completed
  function toggleTask(id) {
    setTasks(tasks.map(task =>
      task.id === id ? { ...task, completed: !task.completed } : task
    ))
  }

  // Hapus task
  function deleteTask(id) {
    setTasks(tasks.filter(task => task.id !== id))
  }

  // Filter tasks
  const filteredTasks = tasks.filter(task => {
    if (filter === 'active') return !task.completed
    if (filter === 'completed') return task.completed
    return true
  })

  // Hitung stats
  const activeCount = tasks.filter(t => !t.completed).length
  const completedCount = tasks.filter(t => t.completed).length

  return (
    <div className="task-manager">
      <h1>Task Manager</h1>

      {/* Form tambah task */}
      <form onSubmit={addTask} className="task-form">
        <input
          type="text"
          value={newTask}
          onChange={(e) => setNewTask(e.target.value)}
          placeholder="Tambah task baru..."
        />
        <button type="submit">Tambah</button>
      </form>

      {/* Filter buttons */}
      <div className="filters">
        <button
          className={filter === 'all' ? 'active' : ''}
          onClick={() => setFilter('all')}
        >
          All ({tasks.length})
        </button>
        <button
          className={filter === 'active' ? 'active' : ''}
          onClick={() => setFilter('active')}
        >
          Active ({activeCount})
        </button>
        <button
          className={filter === 'completed' ? 'active' : ''}
          onClick={() => setFilter('completed')}
        >
          Completed ({completedCount})
        </button>
      </div>

      {/* Task list */}
      <ul className="task-list">
        {filteredTasks.map(task => (
          <li key={task.id} className={task.completed ? 'completed' : ''}>
            <input
              type="checkbox"
              checked={task.completed}
              onChange={() => toggleTask(task.id)}
            />
            <span>{task.text}</span>
            <button
              className="delete-btn"
              onClick={() => deleteTask(task.id)}
            >
              ×
            </button>
          </li>
        ))}
      </ul>

      {filteredTasks.length === 0 && (
        <p className="empty-message">Tidak ada task</p>
      )}
    </div>
  )
}

export default TaskManager
