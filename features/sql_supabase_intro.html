1. Apa itu Database SQL?

Database adalah tempat terstruktur untuk menyimpan data secara permanen. SQL (Structured Query Language) adalah bahasa standar internasional untuk berkomunikasi dengan database relasional.

Dengan database kamu bisa:

  • ✅ Menyimpan data dengan terstruktur
  • ✅ Mencari data dengan sangat cepat
  • ✅ Mengelola jutaan data dengan mudah
  • ✅ Memastikan data aman dan konsisten
  • ✅ Bisa diakses oleh banyak pengguna secara bersamaan

2. Pengenalan Supabase

Supabase adalah platform open source yang menyediakan backend sebagai service lengkap dengan database PostgreSQL. Supabase mengelola semua urusan server, maintenance, backup, dan security sehingga kamu cukup fokus membuat aplikasi.

Keunggulan Supabase:

  • ✅ Database PostgreSQL Full
  • ✅ Auto Generate API Otomatis
  • ✅ Authentication siap pakai
  • ✅ Realtime Subscription
  • ✅ Storage untuk file
  • ✅ Gratis untuk project kecil

📝 Contoh:

Alur kerja menggunakan Supabase:

1. Daftar akun Supabase 2. Buat project baru (1 klik) 3. Buat tabel lewat dashboard 4. Panggil data dari aplikasi dengan API

3. Membuat Project di Supabase

Langkah demi langkah membuat project pertama kamu di Supabase:

  1. Buka situs supabase.com
  2. Klik Start Your Project
  3. Login dengan Github
  4. Klik New Project
  5. Isi nama project, password, dan pilih region
  6. Tunggu sekitar 2 menit sampai project siap

Setelah project siap kamu akan mendapatkan:

  • URL Project
  • API Key Anonymous
  • Dashboard Admin untuk mengelola database

📝 Contoh:

✅ Halaman Dashboard Supabase:

Di sebelah kiri ada menu: Table Editor, SQL Editor, Authentication, Storage, dan lain-lain

Semua konfigurasi database bisa kamu lakukan lewat browser tanpa install software apapun

4. Membuat Tabel di Supabase

Table Editor adalah fitur Supabase yang memudahkan kamu membuat dan mengedit tabel secara visual tanpa menulis kode SQL.

Cara membuat tabel:

  1. Buka menu Table Editor
  2. Klik Create Table
  3. Isi nama tabel
  4. Tambahkan kolom dengan tipe data yang sesuai
  5. Tentukan primary key
  6. Klik Save

Tipe data yang sering dipakai:

  • int8 : untuk angka / id
  • varchar : untuk teks pendek
  • text : untuk teks panjang
  • timestamp : untuk tanggal dan waktu
  • boolean : untuk true/false

📝 Contoh:

✅ Contoh membuat tabel produk:

| Nama Kolom | Tipe Data    | Primary Key | Default Value |
|------------|--------------|-------------|---------------|
| id         | int8         | ✅ Yes      | auto increment|
| nama       | varchar(255) | ❌ No       |               |
| harga      | int8         | ❌ No       | 0             |
| stok       | int8         | ❌ No       | 0             |
| aktif      | boolean      | ❌ No       | true          |
| created_at | timestamp    | ❌ No       | now()         |

5. Menjalankan Query SQL di Supabase

Supabase memiliki SQL Editor yang memungkinkan kamu menjalankan query SQL secara langsung di browser. Kamu bisa menjalankan SELECT, INSERT, UPDATE, DELETE, dan bahkan membuat struktur tabel kompleks.

Fitur SQL Editor:

  • ✅ Syntax Highlighting
  • ✅ Auto Complete
  • ✅ Riwayat query
  • ✅ Bisa menyimpan query favorit
  • ✅ Hasil query ditampilkan dalam format tabel

📝 Contoh:

SELECT * FROM produk ORDER BY nama ASC;

✅ Contoh query untuk melihat semua produk

INSERT INTO produk (nama, harga, stok)
VALUES ('Laptop Gaming', 12500000, 15);

✅ Contoh query menambah produk baru

6. Mengakses Data dengan Supabase API

Setelah kamu membuat tabel, Supabase secara otomatis akan membuatkan API yang bisa kamu panggil dari aplikasi frontend. Kamu tidak perlu membuat backend sendiri, semua operasi CRUD sudah tersedia.

Supabase menyediakan official library untuk:

  • Javascript / Typescript
  • React, Vue, Svelte, Next.js
  • Flutter
  • Python
  • Dan banyak bahasa lain

📝 Contoh:

import { createClient } from '@supabase/supabase-js'

const supabase = createClient('URL_PROJECT_KAMU', 'API_KEY_KAMU')

// Ambil semua produk
const { data: produk, error } = await supabase
  .from('produk')
  .select('*')
  .eq('aktif', true)
  .order('nama')

✅ Contoh kode Javascript mengambil data dari Supabase
