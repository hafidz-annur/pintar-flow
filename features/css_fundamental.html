Fundamental CSS

Module CSS Fundamental lengkap dari nol sampai mahir. Pelajari semua konsep dasar CSS yang wajib dipahami oleh setiap web developer. Dari selector, box model, positioning, sampai layout modern dengan Flexbox dan Grid.

🎯 Learning Objectives

  • ✅ Memahami apa itu CSS dan cara kerjanya di browser
  • ✅ Bisa menggunakan berbagai jenis selector CSS
  • ✅ Memahami Box Model secara mendalam
  • ✅ Memahami perbedaan tipe display element
  • ✅ Bisa melakukan positioning element dengan benar
  • ✅ Menguasai Flexbox untuk layout satu dimensi
  • ✅ Menguasai CSS Grid untuk layout dua dimensi
  • ✅ Memahami Responsive Design dasar
  • ✅ Mengetahui best practice penulisan CSS

1. Pengenalan CSS

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk memberikan style dan tampilan pada dokumen HTML. CSS memisahkan konten dari tampilan.

✅ 3 Cara Memasukkan CSS:

  1. 1. Inline CSS: style attribute di tag HTML
  2. 2. Internal CSS: Tag <style> di dalam <head>
  3. 3. External CSS: File .css terpisah yang di-import

2. Selector CSS

/* Element Selector */
p { color: red; }

/* Class Selector */
.text-primary { color: blue; }

/* ID Selector */
#header { background: gray; }

/* Attribute Selector */
input[type="text"] { border: 1px solid; }

/* Descendant Selector */
.container p { margin: 10px; }

/* Pseudo Class */
button:hover { background: darkblue; }

3. Box Model

Setiap element HTML adalah sebuah kotak yang terdiri dari 4 bagian:
  1. 1. Content: Isi sebenarnya dari element
  2. 2. Padding: Ruang kosong di dalam element
  3. 3. Border: Garis pembatas di sekitar padding
  4. 4. Margin: Ruang kosong di luar element
.box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 2px solid black;
  margin: 10px;
}
✅ Penting! box-sizing: border-box membuat total ukuran element tidak berubah ketika menambah padding dan border.

4. Display Property

Value Keterangan
block Memenuhi lebar penuh, bisa atur width height
inline Hanya selebar konten, tidak bisa atur width height
inline-block Seperti inline tapi bisa atur ukuran
none Element dihilangkan dari halaman
flex Mengaktifkan Flexbox Layout
grid Mengaktifkan Grid Layout

5. Positioning

Value Keterangan
static Default, posisi normal
relative Posisi relatif dari posisi aslinya
absolute Posisi relatif terhadap parent terdekat yang position bukan static
fixed Tetap di posisi yang sama meskipun scroll
sticky Gabungan relative dan fixed

6. Flexbox

.container {
  display: flex;
  justify-content: center; /* align horizontal */
  align-items: center; /* align vertical */
  gap: 20px; /* jarak antar item */
}
✅ Property Container:
  • flex-direction, justify-content, align-items
  • flex-wrap, gap
✅ Property Item:
  • flex-grow, flex-shrink, align-self, order

7. CSS Grid

.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto;
  gap: 20px;
}
Dengan Grid kamu bisa membuat layout apapun dengan sangat mudah dan bersih.

8. Responsive Design Dasar

✅ 3 Komponen Utama:
  1. 1. Meta Viewport:
  2. 2. Media Query
  3. 3. Unit Relative (% , rem, em, vw, vh)
/* Untuk layar dibawah 768px */
@media (max-width: 768px) {
  .container {
    grid-template-columns: 1fr;
  }
}

9. Best Practice CSS

✅ Best Practice Penulisan CSS:

  1. 1. Gunakan class selector bukan ID selector
  2. 2. Gunakan nama class yang deskriptif dan bermakna
  3. 3. Jangan gunakan !important jika tidak benar-benar perlu
  4. 4. Gunakan External CSS
  5. 5. Urutkan property secara logis
  6. 6. Gunakan preprocessor untuk project besar
  7. 7. Selalu gunakan box-sizing: border-box untuk semua element
  8. 8. Hindari nested selector terlalu dalam

10. Kesimpulan

CSS adalah salah satu pilar utama dari web development. Dengan memahami semua konsep fundamental di atas kamu sudah punya dasar yang sangat kuat untuk menjadi web developer profesional.

Setelah menguasai fundamental ini, kamu bisa lanjut mempelajari framework CSS seperti Bootstrap atau TailwindCSS.
