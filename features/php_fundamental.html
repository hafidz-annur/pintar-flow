PHP Fundamental

Module ini akan mempelajari dasar-dasar pemrograman PHP, bahasa scripting server-side yang paling banyak digunakan di dunia untuk pengembangan website. Anda akan mempelajari sintaks dasar, tipe data, variabel, fungsi, struktur kontrol, dan konsep dasar pemrograman dengan PHP.

1. Pengenalan PHP

PHP (Hypertext Preprocessor) adalah bahasa pemrograman server-side open source yang dirancang khusus untuk pengembangan web. PHP dapat disematkan langsung ke dalam dokumen HTML dan akan dieksekusi di server sebelum dikirimkan ke browser pengguna.

PHP sangat populer karena:

  • Mudah dipelajari untuk pemula
  • Bisa berjalan di hampir semua sistem operasi
  • Mendukung hampir semua database yang ada
  • Memiliki komunitas yang sangat besar
  • Gratis dan open source

Contoh penggunaan PHP:

  • Website dinamis
  • Sistem manajemen konten (WordPress, Drupal, Joomla)
  • E-commerce
  • API backend
  • Aplikasi web skala besar

📝 Contoh:

// Ini adalah kode PHP pertama
echo "Hello World! Selamat belajar PHP";

2. Variabel dan Tipe Data

Variabel adalah tempat penyimpanan data yang nilainya bisa berubah-ubah. Di PHP, variabel diawali dengan tanda dollar $ diikuti nama variabel.

Tipe data dasar di PHP:

  1. String - Teks / kalimat
  2. Integer - Bilangan bulat
  3. Float - Bilangan desimal
  4. Boolean - Nilai true/false
  5. Array - Kumpulan data
  6. NULL - Variabel tanpa nilai

Aturan penamaan variabel PHP:

  • Harus dimulai dengan huruf atau underscore
  • Tidak boleh dimulai dengan angka
  • Hanya boleh mengandung huruf, angka, dan underscore
  • Case sensitive ($nama berbeda dengan $Nama)

📝 Contoh:

// Contoh variabel dan tipe data
$nama = "Ahmad"; // String
$umur = 25; // Integer
$tinggi = 175.5; // Float
$mahasiswa = true; // Boolean
$alamat = NULL; // NULL

// Menampilkan nilai variabel
echo "Nama: " . $nama;
echo "
";
echo "Umur: " . $umur . " tahun";

3. Operator

Operator adalah simbol yang digunakan untuk melakukan operasi pada variabel dan nilai.

Jenis operator di PHP:

  • Aritmatika: + - * / % **
  • Penugasan: = += -= *= /= .=
  • Perbandingan: == === != !== > < >= <=
  • Logika: && || !
  • Concatenation: . (titik) untuk menggabungkan string

📝 Contoh:

$a = 10;
$b = 3;

echo $a + $b; // 13
echo $a - $b; // 7
echo $a * $b; // 30
echo $a / $b; // 3.333333...
echo $a % $b; // 1 (sisa bagi)

// Operator perbandingan
var_dump($a > $b); // bool(true)
var_dump($a == 10); // bool(true)

4. Struktur Kontrol Percabangan

Struktur kontrol digunakan untuk mengatur alur eksekusi program berdasarkan kondisi tertentu.

Jenis percabangan di PHP:

  1. if else elseif
  2. switch

Percabangan memungkinkan program membuat keputusan dan menjalankan kode yang berbeda tergantung pada kondisi yang terpenuhi.

📝 Contoh:

$nilai = 85;

if ($nilai >= 90) {
    echo "Nilai A";
} elseif ($nilai >= 80) {
    echo "Nilai B";
} elseif ($nilai >= 70) {
    echo "Nilai C";
} elseif ($nilai >= 60) {
    echo "Nilai D";
} else {
    echo "Nilai E";
}

// Contoh switch
$hari = 3;
switch ($hari) {
    case 1: echo "Senin"; break;
    case 2: echo "Selasa"; break;
    case 3: echo "Rabu"; break;
    case 4: echo "Kamis"; break;
    case 5: echo "Jumat"; break;
    default: echo "Akhir Pekan";
}

5. Perulangan (Loop)

Perulangan digunakan untuk menjalankan blok kode berulang kali selama kondisi tertentu terpenuhi.

Jenis perulangan di PHP:

  1. for - Perulangan dengan jumlah yang sudah diketahui
  2. while - Perulangan selama kondisi true
  3. do...while - Perulangan minimal dijalankan 1x
  4. foreach - Khusus perulangan array

📝 Contoh:

// Contoh for
for ($i = 1; $i <= 5; $i++) {
    echo "Nomor: " . $i . "
";
}

// Contoh while
$angka = 1;
while ($angka <= 5) {
    echo $angka . " ";
    $angka++;
}

// Contoh foreach
$buah = ["Apel", "Mangga", "Jeruk"];
foreach ($buah as $b) {
    echo $b . "
";
}

6. Fungsi

Fungsi adalah blok kode yang dapat dipanggil berulang kali untuk menjalankan tugas tertentu. Fungsi dapat menerima parameter dan mengembalikan nilai.

Keuntungan menggunakan fungsi:

  • Kode menjadi lebih terorganisir
  • Mengurangi duplikasi kode
  • Mudah di maintenance
  • Dapat digunakan kembali

📝 Contoh:

// Membuat fungsi
function hitungLuasPersegi($sisi) {
    $luas = $sisi * $sisi;
    return $luas;
}

// Memanggil fungsi
echo hitungLuasPersegi(5); // 25
echo hitungLuasPersegi(7); // 49

// Fungsi dengan default parameter
function sapa($nama = "Tamu") {
    return "Halo, " . $nama . "!";
}

echo sapa(); // Halo, Tamu!
echo sapa("Budi"); // Halo, Budi!

7. Array

Array adalah variabel yang dapat menyimpan banyak nilai sekaligus dalam satu variabel. Setiap nilai di array memiliki indeks atau kunci untuk mengaksesnya.

Jenis array di PHP:

  1. Array Numerik - Indeks berupa angka
  2. Array Asosiatif - Indeks berupa string (key)
  3. Array Multidimensi - Array di dalam array

📝 Contoh:

// Array Numerik
$mahasiswa = ["Ahmad", "Budi", "Citra"];
echo $mahasiswa[0]; // Ahmad

// Array Asosiatif
$user = [
    "nama" => "Dian",
    "umur" => 28,
    "email" => "dian@email.com"
];
echo $user["email"]; // dian@email.com

// Menampilkan semua isi array
print_r($user);
var_dump($user);
