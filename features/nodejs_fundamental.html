Node.js Fundamental

Module ini akan memperkenalkan kamu tentang dasar-dasar Node.js, runtime JavaScript yang memungkinkan kamu menjalankan kode JavaScript di sisi server. Kamu akan mempelajari konsep inti, cara kerja Node.js, dan bagaimana membangun aplikasi backend sederhana.

🎯 Learning Objectives

  • ✅ Memahami apa itu Node.js dan kegunaannya
  • ✅ Mengetahui arsitektur dan cara kerja Node.js
  • ✅ Dapat membuat server HTTP sederhana dengan Node.js
  • ✅ Memahami sistem module Node.js (CommonJS)
  • ✅ Dapat bekerja dengan file sistem menggunakan Node.js
  • ✅ Memahami konsep asynchronous dan event loop di Node.js

1. Pengenalan Node.js

Node.js adalah runtime JavaScript open-source yang dibangun di atas engine V8 Google Chrome. Berbeda dengan JavaScript yang biasanya berjalan di browser, Node.js memungkinkan kamu menjalankan kode JavaScript di server, komputer lokal, atau perangkat apapun tanpa membutuhkan browser.

Node.js dirancang dengan arsitektur event-driven dan non-blocking I/O yang membuatnya sangat ringan dan efisien. Ini menjadikan Node.js sangat cocok untuk membangun aplikasi real-time, API, microservice, dan aplikasi data-intensive.

📝 Contoh:

# Untuk memeriksa apakah Node.js sudah terinstal
node --version

# Untuk menjalankan file JavaScript dengan Node.js
node app.js

2. Module System (CommonJS)

Node.js menggunakan sistem module CommonJS dimana setiap file JavaScript dianggap sebagai module terpisah. Kamu bisa mengekspor fungsi, variabel, atau objek dari satu file dan mengimpornya di file lain.

Ada 3 jenis module di Node.js:

  1. Core Modules - Module bawaan Node.js (http, fs, path, os dll)
  2. Local Modules - Module yang kamu buat sendiri
  3. Third Party Modules - Module yang diinstall dari NPM

📝 Contoh:

// file: math.js
function tambah(a, b) {
  return a + b;
}

function kurang(a, b) {
  return a - b;
}

module.exports = { tambah, kurang };

// file: app.js
const { tambah, kurang } = require('./math');

console.log(tambah(5, 3)); // Output: 8
console.log(kurang(10, 4)); // Output: 6

3. Membuat Server HTTP

Salah satu fitur paling umum dari Node.js adalah kemampuan untuk membuat web server tanpa membutuhkan software web server eksternal seperti Apache atau Nginx. Node.js menyediakan core module `http` yang bisa kamu gunakan untuk membuat server HTTP.

Setiap request ke server akan memicu event, dan kamu menentukan bagaimana server merespon setiap request tersebut.

📝 Contoh:

// file: server.js
const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello World dari Node.js!');
});

const PORT = 3000;
server.listen(PORT, () => {
  console.log(`Server berjalan di http://localhost:${PORT}`);
});

Jalankan server dengan perintah: node server.js

4. File System (fs Module)

Node.js menyediakan core module `fs` (file system) yang memungkinkan kamu untuk berinteraksi dengan file sistem di komputer. Kamu bisa membaca file, menulis file, menghapus file, membuat folder, dan operasi file lainnya.

Module fs menyediakan 2 jenis operasi:

  • Synchronous (blocking) - Menunggu operasi selesai sebelum melanjutkan kode selanjutnya
  • Asynchronous (non-blocking) - Tidak menunggu, menjalankan callback ketika operasi selesai

📝 Contoh:

const fs = require('fs');

// Membaca file secara Asynchronous
fs.readFile('data.txt', 'utf8', (err, data) => {
  if (err) {
    console.error('Error membaca file:', err);
    return;
  }
  console.log('Isi file:', data);
});

// Menulis file
const konten = 'Ini adalah konten yang akan ditulis ke file';
fs.writeFile('output.txt', konten, (err) => {
  if (err) {
    console.error('Error menulis file:', err);
    return;
  }
  console.log('File berhasil ditulis');
});

5. Event Loop dan Asynchronous

Event Loop adalah jantung dari Node.js yang membuatnya bisa menangani banyak request secara bersamaan dengan single thread. Berbeda dengan model thread-per-request, Node.js menggunakan event loop yang memproses operasi I/O di background dan menjalankan callback ketika operasi selesai.

Ini adalah alasan mengapa Node.js sangat efisien untuk operasi I/O intensive seperti API, database access, dan operasi file.

📝 Contoh:

console.log('Mulai');

setTimeout(() => {
  console.log('Timeout selesai');
}, 0);

Promise.resolve().then(() => {
  console.log('Promise selesai');
});

console.log('Selesai');

Output:

Mulai
Selesai
Promise selesai
Timeout selesai

Ini menunjukkan urutan eksekusi event loop di Node.js.
