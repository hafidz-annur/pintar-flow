1. Apa Itu Laravel?

Laravel adalah framework PHP open source yang paling populer di dunia saat ini, dibuat oleh Taylor Otwell pada tahun 2011. Laravel mengikuti pola arsitektur MVC (Model-View-Controller) dan menyediakan banyak fitur bawaan yang membuat development menjadi lebih cepat dan menyenangkan.

✅ Keunggulan Laravel:

  • Sintaks yang elegan dan ekspresif
  • Banyak fitur bawaan (authentication, authorization, cache, queue, mail, dll)
  • Dokumentasi yang sangat lengkap dan jelas
  • Komunitas terbesar di dunia PHP
  • Banyak paket dan library pihak ketiga
  • Sangat cocok untuk aplikasi skala kecil sampai enterprise

2. Instalasi Laravel

Ada 2 cara instalasi Laravel yang paling umum:

Cara 1: Menggunakan Composer Create Project

composer create-project laravel/laravel nama-project

Cara 2: Menggunakan Laravel Installer

# Install laravel installer
composer global require laravel/installer

# Buat project baru
laravel new nama-project
Setelah instalasi selesai jalankan development server: 
cd nama-project
php artisan serve
Akses aplikasi di browser: http://localhost:8000

3. Struktur Folder Laravel

Folder Fungsi
app/ Tempat kode aplikasi kamu (Model, Controller, Service, dll)
routes/ Semua definisi route aplikasi
resources/views/ Template view / halaman HTML
database/ Migration, seeder, dan factory
config/ Semua file konfigurasi aplikasi
public/ File publik (css, js, gambar, index.php)
storage/ File yang di generate aplikasi (log, cache, upload)

4. Routing

Routing adalah cara mendefinisikan URL aplikasi dan apa yang akan dilakukan ketika URL tersebut diakses. Semua route didefinisikan di file routes/web.php 

// Route GET sederhana
Route::get('/hello', function () {
    return 'Hello World!';
});

// Route dengan parameter
Route::get('/user/{id}', function ($id) {
    return 'User ID: ' . $id;
});

// Route yang menunjuk ke Controller
Route::get('/dashboard', [DashboardController::class, 'index']);
✅ Jenis HTTP Method yang umum digunakan: get, post, put, patch, delete

5. Controller

Controller adalah class yang menangani logika aplikasi. Daripada menulis semua logika di route, lebih baik dipisahkan ke dalam Controller agar kode lebih terstruktur. 

php artisan make:controller UserController
class UserController extends Controller
{
    // Method untuk menampilkan daftar user
    public function index()
    {
        return view('user.index');
    }

    // Method untuk menampilkan detail user
    public function show($id)
    {
        return view('user.show', ['id' => $id]);
    }
}

6. View dan Blade Templating

View adalah tampilan / halaman HTML yang akan ditampilkan ke user. Laravel menggunakan template engine bernama Blade yang sangat powerful. 

<!DOCTYPE html>
<html>
<head>
    <title>My App</title>
</head>
<body>
    <h1>Hello, {{ $name }}</h1>

    @if ($age > 17)
        <p>Kamu sudah dewasa</p>
    @else
        <p>Kamu masih anak-anak</p>
    @endif

    @foreach ($users as $user)
        <p>{{ $user->nama }}</p>
    @endforeach
</body>
</html>
✅ Fitur Blade yang paling sering digunakan:
  • {{ }} untuk echo variabel
  • @if, @foreach untuk control structure
  • @extends, @section untuk template inheritance

7. Database Migration

php artisan make:migration create_users_table
public function up()
{
    Schema::create('users', function (Blueprint $table) {
        $table->id();
        $table->string('nama');
        $table->string('email')->unique();
        $table->timestamp('email_verified_at')->nullable();
        $table->string('password');
        $table->rememberToken();
        $table->timestamps();
    });
}
php artisan migrate

8. Eloquent ORM Dasar

// Ambil semua user
$users = User::all();

// Ambil user berdasarkan ID
$user = User::find(1);

// Buat user baru
$user = new User();
$user->nama = 'Andi';
$user->email = 'andi@example.com';
$user->password = Hash::make('rahasia');
$user->save();

// Update user
$user = User::find(1);
$user->nama = 'Andi Update';
$user->save();

// Hapus user
User::destroy(1);
