1. SQL JOIN

JOIN adalah fitur paling penting di SQL untuk menggabungkan data dari 2 tabel atau lebih berdasarkan hubungan antar kolom. Dalam database relasional, data tidak disimpan dalam satu tabel besar, melainkan dipecah menjadi beberapa tabel yang saling berhubungan.

Jenis JOIN yang umum digunakan:

  • ✅ INNER JOIN: Mengambil data yang cocok di kedua tabel
  • ✅ LEFT JOIN: Mengambil semua data dari tabel kiri + data yang cocok dari tabel kanan
  • ✅ RIGHT JOIN: Mengambil semua data dari tabel kanan + data yang cocok dari tabel kiri
  • ✅ FULL JOIN: Mengambil semua data dari kedua tabel

📝 Contoh:

SELECT 
  users.nama,
  orders.no_order,
  orders.total
FROM users
INNER JOIN orders ON users.id = orders.user_id;

✅ Contoh INNER JOIN untuk menggabungkan tabel users dan orders

SELECT 
  users.nama,
  orders.no_order
FROM users
LEFT JOIN orders ON users.id = orders.user_id
WHERE orders.id IS NULL;

✅ Contoh LEFT JOIN untuk melihat user yang belum pernah order

2. Aggregate Functions

Aggregate Function adalah fungsi bawaan SQL untuk melakukan perhitungan pada sekelompok baris dan menghasilkan satu nilai ringkasan. Ini sangat berguna untuk membuat laporan, statistik, dan analisis data.

Fungsi aggregate yang sering digunakan:

  • COUNT() : Menghitung jumlah baris
  • SUM() : Menjumlahkan nilai numerik
  • AVG() : Menghitung rata-rata
  • MAX() : Mendapatkan nilai tertinggi
  • MIN() : Mendapatkan nilai terendah

📝 Contoh:

SELECT COUNT(*) AS total_users FROM users;

✅ Hitung total user terdaftar

SELECT 
  SUM(total) AS total_pendapatan,
  AVG(total) AS rata_rata_order,
  MAX(total) AS order_terbesar,
  MIN(total) AS order_terkecil
FROM orders;

✅ Hitung total pendapatan semua order

3. GROUP BY Clause

GROUP BY digunakan untuk mengelompokkan baris yang memiliki nilai sama pada kolom tertentu, biasanya digunakan bersama dengan aggregate function. Tanpa GROUP BY, aggregate function hanya akan menghasilkan 1 baris untuk seluruh tabel.

Aturan penting GROUP BY:

  1. Semua kolom yang dipilih yang bukan aggregate HARUS ada di GROUP BY
  2. Bisa grouping lebih dari satu kolom sekaligus
  3. Urutan GROUP BY mempengaruhi hasil

📝 Contoh:

SELECT 
  status,
  COUNT(*) AS jumlah_order
FROM orders
GROUP BY status;

✅ Hitung jumlah order per status

SELECT 
  DATE_FORMAT(created_at, '%Y-%m') AS bulan,
  COUNT(*) AS jumlah_order,
  SUM(total) AS total_penjualan
FROM orders
GROUP BY DATE_FORMAT(created_at, '%Y-%m')
ORDER BY bulan DESC;

✅ Hitung total penjualan per bulan

4. HAVING Clause

HAVING digunakan untuk memfilter hasil setelah GROUP BY dan aggregate function dijalankan. Perbedaan dengan WHERE: WHERE memfilter baris SEBELUM grouping, HAVING memfilter kelompok SETELAH grouping.

Kamu tidak bisa menggunakan aggregate function di WHERE, gunakan HAVING untuk itu.

📝 Contoh:

SELECT 
  kota,
  COUNT(*) AS jumlah_user
FROM users
GROUP BY kota
HAVING COUNT(*) > 10
ORDER BY jumlah_user DESC;

✅ Tampilkan kota yang memiliki lebih dari 10 user

SELECT 
  produk_id,
  SUM(kuantitas) AS total_terjual
FROM order_items
GROUP BY produk_id
HAVING SUM(kuantitas) > 50;

✅ Tampilkan produk yang terjual lebih dari 50 buah

5. Subquery

Subquery adalah query SQL yang berada di dalam query lain. Subquery dapat digunakan di WHERE, FROM, atau SELECT clause. Ini memungkinkan kamu menulis query yang sangat kompleks dalam satu perintah.

Jenis Subquery:

  1. Scalar Subquery: Mengembalikan 1 nilai
  2. Row Subquery: Mengembalikan 1 baris
  3. Table Subquery: Mengembalikan banyak baris

📝 Contoh:

SELECT nama, email
FROM users
WHERE id IN (
  SELECT user_id 
  FROM orders 
  WHERE total > (
    SELECT AVG(total) FROM orders
  )
);

✅ Dapatkan user yang melakukan order diatas rata-rata

SELECT 
  rata_rata_per_bulan.total,
  rata_rata_per_bulan.bulan
FROM (
  SELECT 
    DATE_FORMAT(created_at, '%Y-%m') AS bulan,
    AVG(total) AS total
  FROM orders
  GROUP BY bulan
) AS rata_rata_per_bulan
WHERE total > 500000;

✅ Gunakan Subquery di FROM

6. Table Constraints

Constraints adalah aturan yang diterapkan pada kolom tabel untuk memastikan integritas dan keakuratan data. Constraints mencegah data yang tidak valid masuk ke dalam database.

Constraints umum:

  • PRIMARY KEY: Identitas unik setiap baris
  • FOREIGN KEY: Memastikan hubungan antar tabel valid
  • UNIQUE: Memastikan nilai kolom tidak ada yang sama
  • NOT NULL: Kolom tidak boleh kosong
  • DEFAULT: Memberi nilai default jika tidak diisi
  • CHECK: Memastikan nilai memenuhi kondisi tertentu

📝 Contoh:

CREATE TABLE products (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nama VARCHAR(255) NOT NULL,
  sku VARCHAR(50) UNIQUE NOT NULL,
  harga INT NOT NULL CHECK (harga > 0),
  stok INT DEFAULT 0,
  kategori_id INT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (kategori_id) REFERENCES categories(id)
);

✅ Contoh pembuatan tabel dengan constraints lengkap
