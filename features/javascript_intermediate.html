1. Scope & Closure

Scope adalah aturan yang menentukan dimana variabel bisa diakses di dalam kode. Ada 3 jenis scope di Javascript: Global Scope, Function Scope, dan Block Scope.

Closure adalah kemampuan function untuk "mengingat" variabel yang ada di scope luarnya meskipun function tersebut sudah selesai dijalankan. Closure adalah salah satu konsep paling powerful dan paling banyak ditanyakan di interview.

📝 Contoh:

// Closure Example
function buatCounter() {
  let hitung = 0;
  
  return function() {
    hitung++;
    return hitung;
  }
}

const counter1 = buatCounter();
const counter2 = buatCounter();

console.log(counter1()); // 1
console.log(counter1()); // 2
console.log(counter1()); // 3

console.log(counter2()); // 1 (independen)

2. ES6+ Modern Features

ES6 (ECMAScript 2015) membawa banyak fitur baru yang merubah cara kita menulis Javascript. Fitur ini sekarang sudah menjadi standar dan wajib dipahami oleh setiap developer.

Fitur yang paling penting:

  • let dan const menggantikan var
  • Arrow Function () => {}
  • Template Literal `string ${variabel}`
  • Destructuring Object & Array
  • Spread Operator ...
  • Default Parameter
  • Module Import / Export

📝 Contoh:

// Destructuring Object
const user = {
  nama: "Andi",
  umur: 25,
  alamat: {
    kota: "Jakarta",
    provinsi: "DKI"
  }
};

const { nama, umur, alamat: { kota } } = user;

// Spread Operator
const array1 = [1, 2, 3];
const array2 = [4, 5, 6];
const gabungan = [...array1, ...array2];

// Arrow Function
const kaliDua = x => x * 2;

3. Array Methods

Javascript memiliki banyak method array yang sangat powerful untuk memanipulasi data. Method ini akan membuat kode kamu jauh lebih bersih dibanding menggunakan perulangan for manual.

Method yang paling sering digunakan:

  • map() : Mengubah setiap elemen array
  • filter() : Memilih elemen yang sesuai kondisi
  • reduce() : Mengubah array menjadi 1 nilai
  • find() : Mencari 1 elemen yang sesuai
  • some() : Apakah ada minimal 1 elemen yang sesuai
  • every() : Apakah SEMUA elemen sesuai

📝 Contoh:

const produk = [
  { nama: "Laptop", harga: 10000000, kategori: "elektronik" },
  { nama: "Mouse", harga: 250000, kategori: "elektronik" },
  { nama: "Buku", harga: 50000, kategori: "buku" },
  { nama: "Smartphone", harga: 7000000, kategori: "elektronik" }
];

// Filter produk elektronik dibawah 8 juta
const hasil = produk
  .filter(p => p.kategori === "elektronik")
  .filter(p => p.harga < 8000000)
  .map(p => p.nama);

console.log(hasil); // ["Mouse", "Smartphone"]

4. Asynchronous Javascript Dasar

Javascript adalah bahasa single-threaded, tapi bisa melakukan operasi asynchronous. Artinya Javascript bisa menjalankan operasi yang memakan waktu (seperti request API) tanpa memblokir eksekusi kode lain.

Konsep asynchronous yang harus kamu pahami:

  • Callback Function
  • Callback Hell
  • Promise
  • Async / Await

📝 Contoh:

// Promise
function ambilDataUser() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      const data = { nama: "Andi", umur: 25 };
      resolve(data);
    }, 2000);
  });
}

// Async Await
async function main() {
  console.log("Memuat data...");
  const user = await ambilDataUser();
  console.log("Data diterima:", user);
}

main();

5. DOM Manipulation Lanjutan

DOM (Document Object Model) adalah representasi struktur halaman web yang bisa dimanipulasi dengan Javascript. Selain mengubah konten, ada banyak operasi DOM lanjutan yang sangat berguna.

📝 Contoh:

// Membuat banyak elemen dengan performa tinggi
const daftar = document.getElementById('daftar');
const fragment = document.createDocumentFragment();

for (let i = 1; i <= 100; i++) {
  const li = document.createElement('li');
  li.textContent = "Item " + i;
  fragment.appendChild(li);
}

daftar.appendChild(fragment);

6. Event Delegation

Event Delegation adalah teknik memasang event listener pada elemen parent daripada memasang di setiap elemen anak. Teknik ini sangat berguna untuk elemen yang dibuat secara dinamis dan juga meningkatkan performance secara signifikan.

Dengan event delegation kamu tidak perlu memasang ulang event listener setiap kali elemen baru ditambahkan ke halaman.

// Event Delegation
const daftar = document.getElementById('daftarTugas');

daftar.addEventListener('click', function(e) {
  if (e.target.classList.contains('hapus')) {
    const li = e.target.closest('li');
    li.remove();
  }
});

7. Event Loop

Event Loop adalah mekanisme yang membuat Javascript bisa melakukan operasi asynchronous padahal hanya single-threaded. Memahami event loop akan menjawab pertanyaan mengapa kode kamu berjalan di urutan yang tidak kamu duga.

Urutan eksekusi:

  1. Call Stack (kode sinkron dijalankan pertama)
  2. Microtask Queue (Promise, process.nextTick)
  3. Macrotask Queue (setTimeout, setInterval, event listener)

📝 Contoh:

console.log(1);

setTimeout(() => console.log(2), 0);

Promise.resolve().then(() => console.log(3));

console.log(4);

// Output:
// 1
// 4
// 3
// 2
