Cara Setup N8N Menggunakan Docker

Module ini menjelaskan langkah demi langkah cara menginstall dan menjalankan N8N self hosted menggunakan Docker dan Docker Compose di server lokal maupun VPS. Termasuk konfigurasi reverse proxy, SSL, dan best practice production.

🎯 Learning Objectives

  • ✅ Bisa menjalankan N8N dengan perintah docker run
  • ✅ Bisa membuat docker-compose.yml untuk N8N
  • ✅ Memahami volume dan persistensi data N8N
  • ✅ Bisa melakukan konfigurasi environment variable
  • ✅ Bisa setup reverse proxy dengan Nginx
  • ✅ Bisa setup SSL dengan Letsencrypt
  • ✅ Memahami best practice menjalankan N8N di production
  • ✅ Bisa melakukan update N8N dengan aman

1. Persiapan Awal

Yang kamu butuhkan sebelum mulai:

  • ✅ Docker dan Docker Compose sudah terinstall
  • ✅ Server / VPS dengan minimal 2GB RAM
  • ✅ Domain name (jika ingin akses publik)
  • ✅ Port 80 dan 443 terbuka di firewall

Minimum

  • CPU: 1 Core
  • RAM: 2 GB
  • Storage: 20 GB SSD

Rekomendasi

  • CPU: 2 Core
  • RAM: 4 GB
  • Storage: 40 GB SSD

2. Menjalankan N8N dengan Docker Run

Cara tercepat menjalankan N8N hanya dengan satu perintah docker run. Ini cocok untuk testing dan penggunaan lokal.

📝 Contoh:

# Jalankan N8N dengan Docker
docker run -it --rm --name n8n -p 5678:5678 n8nio/n8n
Setelah berjalan kamu bisa akses N8N di browser: http://localhost:5678
⚠️ Ini akan menjalankan N8N tapi semua data akan hilang ketika container dihentikan.

3. Menjalankan N8N dengan Volume Persistensi

Untuk menyimpan data workflow, credential, dan konfigurasi secara permanen kamu butuh mount volume ke dalam container.

📝 Contoh:

# Buat volume untuk n8n
docker volume create n8n_data

# Jalankan N8N dengan volume
docker run -d \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  --restart unless-stopped \
  n8nio/n8n

✅ Data sekarang akan tersimpan meskipun container di restart / dihapus

✅ Container akan otomatis start ketika server reboot

4. Docker Compose Setup

Untuk production sebaiknya gunakan Docker Compose agar konfigurasi lebih terstruktur dan mudah di maintain.

Buat file docker-compose.yml:

version: "3.7"

services:
  n8n:
    image: n8nio/n8n:latest
    restart: unless-stopped
    ports:
      - 5678:5678
    environment:
      - N8N_HOST=n8n.domainkamu.com
      - N8N_PROTOCOL=https
      - NODE_ENV=production
      - GENERIC_TIMEZONE=Asia/Jakarta
    volumes:
      - n8n_data:/home/node/.n8n

volumes:
  n8n_data:
# Jalankan dengan perintah
docker compose up -d

5. Environment Variable Penting

Variable Fungsi
N8N_HOST Domain name kamu
N8N_PROTOCOL http atau https
GENERIC_TIMEZONE Timezone server
N8N_DIAGNOSTICS_ENABLED Nonaktifkan pengiriman data diagnosa

6. Setup Reverse Proxy dengan Nginx

Untuk mengakses N8N dengan domain dan SSL kamu butuh reverse proxy. Berikut adalah konfigurasi Nginx yang paling sederhana: 

server {
    listen 80;
    server_name n8n.domainkamu.com;

    location / {
        proxy_pass http://localhost:5678;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # Websocket support untuk editor N8N
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
💡 Jangan lupa setting Upgrade dan Connection untuk websocket, jika tidak editor N8N tidak akan berfungsi dengan benar.

7. Setup SSL Gratis dengan Letsencrypt

# Install certbot
apt install certbot python3-certbot-nginx

# Dapatkan sertifikat SSL
certbot --nginx -d n8n.domainkamu.com
Certbot akan otomatis mengkonfigurasi Nginx kamu, setup redirect HTTP ke HTTPS, dan setup auto renewal sertifikat.

8. Best Practice Production

  • ✅ Selalu gunakan tag versi spesifik bukan `latest`
  • ✅ Aktifkan autentikasi dengan email dan password
  • ✅ Batasi akses web UI dengan IP jika memungkinkan
  • ✅ Backup volume n8n_data secara berkala
  • ✅ Batasi resource memory dan cpu container
  • ✅ Setup monitoring dan alert
  • ✅ Update N8N secara teratur

9. Cara Update N8N

# 1. Stop container lama
docker compose down

# 2. Backup volume data (PENTING!)
docker run --rm -v n8n_data:/data -v $(pwd):/backup busybox tar czf /backup/n8n-backup-$(date +%Y%m%d).tar.gz /data

# 3. Pull image versi baru
docker compose pull

# 4. Jalankan kembali
docker compose up -d
✅ Selalu backup sebelum melakukan update apapun
✅ Jangan lanjutkan update jika backup belum selesai

10. Troubleshooting

❌ Editor N8N loading terus

✅ Pastikan reverse proxy sudah dikonfigurasi untuk websocket

❌ Data hilang setelah restart

✅ Pastikan kamu sudah mount volume dengan benar

❌ Workflow error tidak berjalan

✅ Cek log container dengan docker compose logs -f n8n

11. Kesimpulan

Menjalankan N8N self hosted dengan Docker adalah cara terbaik untuk mendapatkan kontrol penuh atas data kamu, tanpa batasan apapun, dan dengan biaya yang jauh lebih murah dibandingkan langganan cloud N8N.

Dengan mengikuti panduan ini kamu sudah punya setup N8N yang siap untuk production dan bisa menangkap ribuan eksekusi workflow per hari.
