1. Service Container

Service Container adalah jantung dari Laravel. Ini adalah object yang bertugas untuk mengelola dependency dan melakukan dependency injection secara otomatis. 

// Mengambil instance dari container
$userService = app(UserService::class);

// Binding interface ke implementasi
app()->bind(PaymentGateway::class, MidtransGateway::class);

// Singleton binding
app()->singleton(CacheManager::class, function () {
    return new CacheManager(config('cache'));
});
✅ Fitur Service Container:
  • Automatic Dependency Injection
  • Binding Interface ke Concrete Class
  • Singleton, Scoped, Transient binding
  • Method Injection
  • Constructor Injection

2. Service Provider

class AppServiceProvider extends ServiceProvider
{
    public function register()
    {
        $this->app->singleton(PaymentGateway::class, function () {
            return new MidtransGateway(
                config('services.midtrans.key')
            );
        });
    }

    public function boot()
    {
        // Jalankan kode setelah semua service di register
    }
}

3. Event & Listener

// Event
class UserRegistered
{
    use Dispatchable, SerializesModels;

    public $user;

    public function __construct(User $user)
    {
        $this->user = $user;
    }
}

// Listener
class SendWelcomeEmail
{
    public function handle(UserRegistered $event)
    {
        Mail::to($event->user->email)
            ->send(new WelcomeEmail($event->user));
    }
}
event(new UserRegistered($user));

4. Queue & Job

class ProcessReport implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    protected $report;

    public function __construct(Report $report)
    {
        $this->report = $report;
    }

    public function handle()
    {
        // Proses generate laporan yang memakan waktu
        $this->report->generate();
    }
}
ProcessReport::dispatch($report)
    ->onQueue('reports')
    ->delay(now()->addMinutes(5));

5. Repository Pattern

interface UserRepository
{
    public function all();
    public function find($id);
    public function create(array $data);
    public function update($id, array $data);
    public function delete($id);
}

class EloquentUserRepository implements UserRepository
{
    protected $model;

    public function __construct(User $model)
    {
        $this->model = $model;
    }

    public function all()
    {
        return $this->model->all();
    }
}

6. Cache & Performance Optimization

// Simpan data ke cache selama 1 jam
Cache::put('popular_posts', $posts, 3600);

// Ambil data dari cache
$posts = Cache::get('popular_posts');

// Ambil atau simpan jika tidak ada
$posts = Cache::remember('popular_posts', 3600, function () {
    return Post::popular()->get();
});

// Hapus cache
Cache::forget('popular_posts');

7. Policy Advanced

class PostPolicy
{
    public function update(User $user, Post $post)
    {
        return $user->id === $post->user_id 
            || $user->is_admin
            || $user->hasPermission('edit-all-posts');
    }

    public function delete(User $user, Post $post)
    {
        return $user->is_admin && $post->status !== 'published';
    }
}

8. Testing

class PostTest extends TestCase
{
    public function test_user_can_create_post()
    {
        $user = User::factory()->create();

        $response = $this->actingAs($user)
            ->post('/posts', [
                'title' => 'Test Post',
                'content' => 'Test Content'
            ]);

        $response->assertRedirect('/posts');
        $this->assertDatabaseHas('posts', [
            'title' => 'Test Post'
        ]);
    }
}

9. Deployment

  1. Upload semua file code ke server
  2. Jalankan composer install --optimize-autoloader --no-dev
  3. Salin file .env dan setting konfigurasi production
  4. Jalankan php artisan config:cache
  5. Jalankan php artisan route:cache
  6. Jalankan php artisan view:cache
  7. Setup Supervisor untuk menjalankan queue worker
  8. Setup cron job untuk scheduler
  9. Setup Web Server (Nginx/Apache)
