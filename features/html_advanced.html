1. Custom Data Attributes & Dataset API

Custom Data Attribute adalah atribut custom yang bisa kamu tambahkan ke elemen HTML apapun dengan prefix data-*. Ini adalah cara official dan standar untuk menyimpan data tambahan pada elemen HTML tanpa menggunakan hack seperti class atau id.

Data yang disimpan disini bisa diakses dengan mudah melalui JavaScript menggunakan dataset API secara native tanpa library apapun. Semua browser modern sudah mendukung fitur ini 100%.

📝 Contoh:

<!-- Menyimpan data di HTML -->
<div 
  id="product" 
  data-id="12345" 
  data-name="Laptop Gaming" 
  data-price="12500000" 
  data-category="elektronik"
  data-in-stock="true"
>
  Laptop Gaming RTX 4060
</div>
// Mengakses data di JavaScript
const product = document.getElementById('product');

console.log(product.dataset.id); // "12345"
console.log(product.dataset.name); // "Laptop Gaming"
console.log(product.dataset.price); // "12500000"
console.log(product.dataset.inStock); // "true" (otomatis dikonversi camelCase)

// Mengubah data
product.dataset.price = "13000000";

2. Template Element

<template> adalah elemen HTML khusus yang isinya tidak akan dirender oleh browser secara default. Konten didalam template hanya berupa blueprint yang bisa kamu kloning dan tampilkan kapan saja dibutuhkan menggunakan JavaScript.

Ini adalah cara paling performant untuk membuat konten yang akan diulang banyak kali di halaman. Jauh lebih baik dibanding membuat string HTML di dalam JavaScript.

📝 Contoh:

<!-- Template yang tidak akan terlihat di halaman -->
<template id="cardUser">
  <div class="card">
    <img src="" alt="Foto" class="avatar">
    <h3 class="nama"></h3>
    <p class="email"></p>
    <button class="btn-hapus">Hapus</button>
  </div>
</template>
// Menggunakan template
const template = document.getElementById('cardUser');
const container = document.getElementById('daftarUser');

users.forEach(user => {
  // Kloning template
  const card = template.content.cloneNode(true);
  
  // Isi data
  card.querySelector('.avatar').src = user.foto;
  card.querySelector('.nama').textContent = user.nama;
  card.querySelector('.email').textContent = user.email;
  
  // Tambahkan ke halaman
  container.appendChild(card);
});

3. Shadow DOM

Shadow DOM adalah fitur browser yang memungkinkan kamu membuat DOM terpisah dan terisolasi didalam elemen biasa. Style dan script didalam shadow DOM tidak akan bocor keluar, dan style luar juga tidak akan mempengaruhi isi shadow DOM.

Ini adalah dasar dari Web Components dan alasan mengapa komponen bisa benar-benar independent tanpa konflik CSS.

📝 Contoh:

<div id="komponenSaya"></div>

<script>
    const host = document.getElementById('komponenSaya');

    // Membuat Shadow Root
    const shadow = host.attachShadow({ mode: 'open' });

    // Menambahkan konten kedalam Shadow DOM
    shadow.innerHTML = `
  <style>
    /* Style ini HANYA berlaku didalam shadow DOM saja */
    h2 {
      color: blue;
      font-size: 20px;
    }
  </style>
  
  <h2>Ini ada didalam Shadow DOM</h2>
  <p>Style disini tidak konflik dengan halaman utama</p>
`;
</script>

4. Meta Tag & Security

Meta tag bukan cuma untuk SEO. Ada banyak meta tag tingkat lanjut yang berfungsi untuk mengontrol perilaku browser, meningkatkan keamanan, dan mencegah serangan.

Beberapa yang paling penting:

  • Content-Security-Policy: Mencegah XSS attack
  • Referrer-Policy: Mengontrol data apa yang dikirim ketika user klik link
  • Permissions-Policy: Menonaktifkan fitur browser yang tidak dibutuhkan
  • X-Frame-Options: Mencegah website di embed oleh situs lain

📝 Contoh:

<head>
  <!-- Keamanan Dasar -->
  <meta http-equiv="X-Frame-Options" content="DENY">
  <meta http-equiv="X-Content-Type-Options" content="nosniff">
  
  <!-- Content Security Policy -->
  <meta http-equiv="Content-Security-Policy" content="
    default-src 'self';
    script-src 'self' https://cdn.jsdelivr.net;
    style-src 'self' 'unsafe-inline';
    img-src 'self' data: https:;
    object-src 'none';
    base-uri 'self';
    form-action 'self';
  ">
  
  <!-- Referrer Policy -->
  <meta name="referrer" content="strict-origin-when-cross-origin">
  
  <!-- Disable Fitur Browser yang tidak dipakai -->
  <meta http-equiv="Permissions-Policy" content="
    camera=(), 
    microphone=(), 
    geolocation=(), 
    payment=()
  ">
</head>

5. Native Drag & Drop

HTML memiliki API Drag & Drop native yang bisa kamu gunakan tanpa library apapun. Fitur ini memungkinkan user menyeret elemen dari satu tempat ke tempat lain di halaman, bahkan antar window browser.

3 konsep utama:

  1. Elemen yang bisa diseret (draggable="true")
  2. Event ketika elemen diseret
  3. Elemen target tempat drop

📝 Contoh:

<div class="daftar-tugas">
  <div class="tugas" draggable="true" data-id="1">Tugas A</div>
  <div class="tugas" draggable="true" data-id="2">Tugas B</div>
  <div class="tugas" draggable="true" data-id="3">Tugas C</div>
</div>

<div class="kolom" id="progress">
  <h3>In Progress</h3>
</div>

<div class="kolom" id="done">
  <h3>Done</h3>
</div>

6. Performance Optimization HTML

Banyak optimasi performance yang bisa dilakukan hanya dengan HTML saja tanpa JavaScript:

  • preload: Memuat resource penting lebih awal
  • prefetch: Memuat resource untuk halaman selanjutnya
  • preconnect: Membuat koneksi awal ke domain lain
  • dns-prefetch: Resolve DNS lebih awal
  • loading="lazy": Lazy load untuk gambar dan iframe
  • decoding="async": Decode gambar tanpa block render

📝 Contoh:

<head>
  <!-- Hubungkan ke CDN sebelum dibutuhkan -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  
  <!-- Preload font penting -->
  <link rel="preload" href="font/poppins.woff2" as="font" type="font/woff2" crossorigin>
  
  <!-- Prefetch halaman yang kemungkinan dikunjungi selanjutnya -->
  <link rel="prefetch" href="/produk/detail.html">
</head>

<body>
  <!-- Gambar dengan optimasi lengkap -->
  <img 
    src="gambar-produk.jpg" 
    alt="Produk" 
    loading="lazy" 
    decoding="async"
    width="800"
    height="600"
  >
</body>

7. Web Components Dasar

Web Components adalah standar browser untuk membuat elemen HTML custom kamu sendiri. Kamu bisa mendefinisikan tag baru yang memiliki fungsi, style dan perilaku sendiri yang bisa dipakai berulang kali di website manapun.

Web Components terdiri dari 3 teknologi:

  1. Custom Elements
  2. Shadow DOM
  3. HTML Templates

📝 Contoh:

// Mendefinisikan Custom Element
class TombolPrimary extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    
    this.shadowRoot.innerHTML = `
      <style>
        button {
          background: #165DFF;
          color: white;
          padding: 12px 24px;
          border: none;
          border-radius: 8px;
          cursor: pointer;
        }
        button:hover {
          opacity: 0.9;
        }
      </style>
      <button><slot></slot></button>
    `;
  }
}

// Daftarkan elemen ke browser
customElements.define('tombol-primary', TombolPrimary);
<!-- Gunakan seperti tag HTML biasa dimanapun -->
<tombol-primary>Klik Disini</tombol-primary>
