HTML Intermediate

Module ini membahas fitur-fitur HTML tingkat menengah yang dibutuhkan untuk membangun website modern dan terstruktur. Setelah menyelesaikan module ini, kamu akan bisa membuat halaman web yang semantik, aksesibel, dan siap untuk diintegrasikan dengan CSS serta JavaScript.

  • ✅ Membuat formulir yang lengkap dengan validasi native
  • ✅ Mengimplementasikan multimedia (gambar, audio, video) dengan optimal
  • ✅ Membuat tabel yang terstruktur dan aksesibel
  • ✅ Memahami konsep aksesibilitas web dasar

1. Elemen Semantik HTML5

Elemen semantik adalah elemen HTML yang memiliki makna jelas baik untuk browser maupun developer. Sebelum HTML5, developer hanya menggunakan

untuk semua bagian halaman. Dengan elemen semantik, struktur halaman menjadi lebih mudah dibaca, membantu mesin pencari (SEO), dan meningkatkan aksesibilitas untuk pengguna dengan screen reader.

Elemen semantik utama yang harus kamu ketahui:

  • <header>: Bagian atas halaman / bagian konten, biasanya berisi logo dan navigasi
  • <nav>: Area khusus untuk menu navigasi
  • <main>: Konten utama halaman (hanya boleh ada 1 per halaman)
  • <section>: Kelompok konten yang memiliki tema sama
  • <article>: Konten yang berdiri sendiri dan bisa dibagikan
  • <aside>: Konten pendukung / sidebar
  • <footer>: Bagian bawah halaman

📝 Contoh:

<body>
  <header>
    <h1>Website Saya</h1>
    <nav>
      <a href="/">Home</a>
      <a href="/about">Tentang</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>Judul Artikel</h2>
      <p>Isi artikel disini...</p>
    </article>

    <aside>
      <h3>Sidebar</h3>
      <p>Informasi tambahan</p>
    </aside>
  </main>

  <footer>
    <p>&copy; 2026 Hak Cipta</p>
  </footer>
</body>

2. Formulir Lanjutan & Validasi

HTML5 menyediakan banyak fitur formulir yang sebelumnya hanya bisa dilakukan dengan JavaScript. Kamu bisa menambahkan validasi, tipe input spesifik, dan atribut kontrol perilaku formulir tanpa kode tambahan.

Atribut penting formulir:

  • required: Menandai field wajib diisi
  • pattern: Validasi menggunakan Regular Expression
  • min, max, step: Kontrol untuk input angka
  • placeholder: Petunjuk isian untuk pengguna
  • autocomplete: Membantu browser mengisi otomatis field

Tipe input baru di HTML5: email, tel, url, number, date, time, color, range

📝 Contoh:

<form action="/daftar" method="POST">

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" required autocomplete="email">

  <label for="telepon">Nomor HP:</label>
  <input type="tel" id="telepon" name="telepon" pattern="[0-9]{10,13}" required>

  <label for="usia">Usia:</label>
  <input type="number" id="usia" name="usia" min="13" max="100" required>

  <label for="tanggal">Tanggal Lahir:</label>
  <input type="date" id="tanggal" name="tanggal_lahir">

  <button type="submit">Daftar Sekarang</button>

</form>

3. Multimedia Optimasi

HTML menyediakan elemen native untuk menampilkan gambar, audio, dan video. Kamu bisa mengoptimalkan pemuatan multimedia agar website tidak lambat dan berjalan baik di semua perangkat.

Konsep penting:

  • srcset & sizes: Menyediakan versi gambar berbeda untuk resolusi layar berbeda
  • loading="lazy": Memuat gambar hanya ketika pengguna menggulir ke area tersebut
  • poster: Gambar thumbnail untuk video sebelum diputar
  • Multiple source: Menyediakan format file berbeda untuk kompatibilitas browser

📝 Contoh:

<!-- Gambar Responsive -->
<img 
  src="gambar-default.jpg" 
  srcset="gambar-kecil.jpg 480w, gambar-sedang.jpg 800w, gambar-besar.jpg 1200w"
  sizes="(max-width: 600px) 480px, (max-width: 900px) 800px, 1200px"
  alt="Deskripsi gambar"
  loading="lazy"
>

<!-- Video -->
<video controls width="100%" poster="thumbnail-video.jpg">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  Browser kamu tidak mendukung tag video.
</video>

<!-- Audio -->
<audio controls>
  <source src="musik.mp3" type="audio/mpeg">
  <source src="musik.ogg" type="audio/ogg">
</audio>

4. Tabel Terstruktur

Tabel HTML bukan cuma baris dan kolom. Kamu bisa membuat struktur tabel yang jelas dan aksesibel dengan memisahkan bagian header, body, dan footer. Gunakan atribut `scope` untuk memberitahu screen reader apakah heading untuk baris atau kolom.

📝 Contoh:

<table>
  <caption>Daftar Nilai Siswa</caption>
  
  <thead>
    <tr>
      <th scope="col">No</th>
      <th scope="col">Nama</th>
      <th scope="col">Nilai</th>
      <th scope="col">Keterangan</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>1</td>
      <td>Andi</td>
      <td>85</td>
      <td>Lulus</td>
    </tr>

    <tr>
      <td>2</td>
      <td>Budi</td>
      <td>72</td>
      <td>Lulus</td>
    </tr>
  </tbody>

  <tfoot>
    <tr>
      <th scope="row" colspan="2">Rata-rata</th>
      <td>78.5</td>
      <td></td>
    </tr>
  </tfoot>

</table>

5. Aksesibilitas Dasar

Aksesibilitas (a11y) adalah praktik membuat website yang bisa digunakan oleh semua orang, termasuk mereka yang memiliki keterbatasan. Beberapa hal dasar yang wajib kamu terapkan di setiap halaman HTML:

  1. Selalu tambahkan `alt` pada setiap gambar
  2. Gunakan heading secara berurutan (h1 → h2 → h3, tidak lompat)
  3. Gunakan elemen semantik bukan hanya <div> dan <span>
  4. Tambahkan `aria-label` untuk elemen yang tidak memiliki teks terlihat
  5. Pastikan semua elemen interaktif bisa diakses dengan keyboard

📝 Contoh:

<!-- Tombol yang aksesibel -->
<button aria-label="Tutup popup">
  ✕
</button>

<!-- Gambar dekoratif tidak butuh deskripsi -->
<img src="garis-dekorasi.png" alt="">

<!-- Link yang jelas -->
<a href="/bantuan">
  Baca panduan selengkapnya
</a>
