1. Request Handling & Validation

Semua data input yang masuk ke aplikasi harus divalidasi terlebih dahulu. Laravel menyediakan sistem validasi yang sangat powerful. 

public function store(Request $request)
{
    $validated = $request->validate([
        'nama' => 'required|string|max:255',
        'email' => 'required|email|unique:users,email',
        'password' => 'required|min:8|confirmed',
        'tanggal_lahir' => 'nullable|date',
    ]);

    // Simpan data ke database
    User::create($validated);

    return redirect()->back();
}
✅ Aturan validasi yang sering digunakan: required, email, unique, min, max, numeric, date, exists, confirmed

2. Authentication

Laravel menyediakan sistem autentikasi lengkap yang tinggal pakai, tidak perlu buat dari nol.

3. Authorization (Gates & Policies)

// Definisikan di AppServiceProvider
Gate::define('update-post', function (User $user, Post $post) {
    return $user->id === $post->user_id;
});

// Gunakan di Controller
if (Gate::allows('update-post', $post)) {
    // User boleh update post
}

4. Eloquent Relationship

class User extends Model
{
    // Satu user punya banyak post
    public function posts()
    {
        return $this->hasMany(Post::class);
    }
}

class Post extends Model
{
    // Satu post milik satu user
    public function user()
    {
        return $this->belongsTo(User::class);
    }
}
✅ Jenis Relationship yang ada:
  • hasOne - Satu ke satu
  • hasMany - Satu ke banyak
  • belongsTo - Kebalikannya hasMany
  • belongsToMany - Banyak ke banyak
  • hasManyThrough - Hubungan melalui tabel lain
  • morphMany - Polymorphic relationship

5. Eager Loading

❌ Masalah N+1 Query:

// Ini akan menjalankan 1 query untuk mengambil semua post
// Dan 1 query untuk setiap post untuk mengambil user
$posts = Post::all();
foreach ($posts as $post) {
    echo $post->user->nama;
}

✅ Solusi dengan Eager Loading:

// Ini hanya menjalankan 2 query saja, tidak peduli berapa jumlah post
$posts = Post::with('user')->get();
foreach ($posts as $post) {
    echo $post->user->nama;
}

7. Form Request

class StorePostRequest extends FormRequest
{
    public function rules()
    {
        return [
            'title' => 'required|max:255',
            'content' => 'required',
        ];
    }
}
public function store(StorePostRequest $request)
{
    // Data sudah tervalidasi otomatis
    Post::create($request->validated());
}

8. File Upload & Storage

public function store(Request $request)
{
    $path = $request->file('gambar')->store('public/posts');

    // Simpan path ke database
    $post->gambar = $path;
    $post->save();
}

9. Soft Deletes

use Illuminate\Database\Eloquent\SoftDeletes;

class Post extends Model
{
    use SoftDeletes;
}
// Soft delete
$post->delete();

// Ambil semua data termasuk yang dihapus
Post::withTrashed()->get();

// Restore data yang dihapus
$post->restore();

// Hapus permanen
$post->forceDelete();
