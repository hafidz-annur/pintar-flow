1. Execution Context & This Binding

Execution Context adalah lingkungan dimana kode Javascript dijalankan. Setiap function dipanggil akan membuat execution context baru yang memiliki 3 komponen: Variable Environment, Lexical Environment, dan This Binding.

Nilai this tidak ditentukan dimana function dideklarasikan, tapi ditentukan BAGAIMANA function tersebut dipanggil.

📝 Contoh:

const user = {
  nama: "Andi",
  sapa: function() {
    console.log(`Halo ${this.nama}`);
  }
};

user.sapa(); // ✅ this = user (implicit)

const sapa = user.sapa;
sapa(); // ❌ this = window / undefined

const sapaDenganBind = user.sapa.bind(user);
sapaDenganBind(); // ✅ this = user (explicit bind)

2. Prototype & Inheritance

Javascript adalah bahasa Prototype-Based, bukan Class-Based. Semua object di Javascript memiliki internal property [[Prototype]] yang menunjuk ke object lain.

Ketika kamu mengakses property yang tidak ada di object, Javascript akan mencarinya di prototype chain sampai akhirnya null. Ini adalah satu-satunya mekanisme inheritance yang ada di Javascript. Class ES6 hanyalah syntactic sugar diatas prototype.

📝 Contoh:

// Prototype Inheritance
function Manusia(nama) {
  this.nama = nama;
}

Manusia.prototype.sapa = function() {
  console.log(`Halo nama saya ${this.nama}`);
};

function Mahasiswa(nama, nim) {
  Manusia.call(this, nama);
  this.nim = nim;
}

// Hubungkan prototype chain
Mahasiswa.prototype = Object.create(Manusia.prototype);
Mahasiswa.prototype.constructor = Mahasiswa;

Mahasiswa.prototype.belajar = function() {
  console.log(`${this.nama} sedang belajar`);
};

const andi = new Mahasiswa("Andi", "12345");
andi.sapa(); // ✅ Bisa memanggil method dari Manusia

3. Closure Advanced & Module Pattern

Closure adalah dasar dari hampir semua pattern design di Javascript. Dengan closure kamu bisa membuat private variable, encapsulation, dan module system sebelum ES6 Module ada.

Module Pattern adalah pattern paling populer untuk membuat kode yang terstruktur, terenkapsulasi, dan tidak mencemari global scope.

📝 Contoh:

// Module Pattern dengan IIFE
const Counter = (function() {
  // Variable PRIVATE (tidak bisa diakses dari luar)
  let hitung = 0;

  return {
    // Method PUBLIC
    tambah: function() {
      hitung++;
    },
    kurangi: function() {
      hitung--;
    },
    getNilai: function() {
      return hitung;
    }
  }
})();

Counter.tambah();
Counter.tambah();
console.log(Counter.getNilai()); // 2
console.log(Counter.hitung); // ❌ undefined (private)

4. Async Javascript Lanjutan

Konsep asynchronous tingkat advance yang harus dikuasai: Promise Chaining & Error Handling, Promise Combinators, async/await best practice, Abort Controller, dan Retry Pattern.

📝 Contoh:

// Promise.allSettled: menunggu SEMUA promise selesai baik sukses maupun gagal
const urls = [
  "https://api.example.com/user/1",
  "https://api.example.com/user/2",
  "https://api.example.com/user/3"
];

const hasil = await Promise.allSettled(
  urls.map(url => fetch(url))
);

hasil.forEach((result, index) => {
  if (result.status === "fulfilled") {
    console.log(`Request ${index} berhasil`);
  } else {
    console.log(`Request ${index} gagal`);
  }
});

5. Event Loop Mendalam

Event Loop adalah jantung dari asynchronous Javascript. Untuk benar-benar memahami Javascript kamu harus memahami setiap bagian dari event loop.

Microtask selalu dijalankan SEMUA SEKALIGUS sebelum browser melakukan render dan sebelum mengambil task dari macrotask queue.

📝 Contoh:

// Tebak outputnya!
console.log(1);

setTimeout(() => console.log(2), 0);

Promise.resolve().then(() => {
  console.log(3);
  setTimeout(() => console.log(4), 0);
  Promise.resolve().then(() => console.log(5));
});

console.log(6);

// Output:
// 1
// 6
// 3
// 5
// 2
// 4

6. Design Pattern Javascript

Design Pattern adalah solusi umum yang sudah teruji untuk masalah yang sering muncul di programming. Pattern yang paling sering dipakai di Javascript: Module, Singleton, Observer, Factory, Decorator, Strategy.

📝 Contoh:

// Singleton Pattern
class Database {
  constructor() {
    if (Database.instance) {
      return Database.instance;
    }
    this.koneksi = this.buatKoneksi();
    Database.instance = this;
  }

  buatKoneksi() {
    console.log("Membuat koneksi database...");
    return {};
  }
}

const db1 = new Database();
const db2 = new Database();
console.log(db1 === db2); // ✅ true (object yang sama)

7. Performance Optimization

Teknik optimasi performance Javascript: Debounce & Throttle, Lazy Loading, Web Worker, requestAnimationFrame(), menghindari Memory Leak, dan Big O Notation.

📝 Contoh:

// Debounce Function
function debounce(fn, delay) {
  let timeoutId;
  return function(...args) {
    clearTimeout(timeoutId);
    timeoutId = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

// Gunakan untuk event search yang tidak perlu request setiap ketik
const search = debounce((keyword) => {
  fetchAPI(keyword);
}, 300);

input.addEventListener('input', (e) => {
  search(e.target.value);
});
